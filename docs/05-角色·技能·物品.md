# 05 · 角色 · 技能 · 物品

> 阅读前置：[02-核心概念](02-核心概念.md)（技能、阵营、技能组、永久物品等术语）。

## 一、角色总览

当前游戏 3 个角色：主角（pro）、夏阳（xiayang）、陆悠悠（luyouyou）。未来可以扩展。

### 1.1 主角（pro）

- **阵营**：我方
- **有生命值系统**（HP / maxHp），归零则战斗失败 / 全局失败
- **有速度属性**（只影响逃跑概率）
- **有行动力属性**（探索时移动消耗；睡觉回满）
- **有健康 / 心理压力属性**（探索时扣；归零全局失败）
- **位置 + 朝向 = 绑定主角自己**（主角就是主角）

### 1.2 队友（xiayang / luyouyou）

- **阵营**：我方
- **没有生命值系统**（不会死亡）
- **没有速度属性**
- **位置 + 朝向 = 永远绑定主角**（主角到哪、队友跟到哪；主角朝向哪、队友朝向哪）
- **没有独立行动节点触发时机**？—— 不，队友有自己的技能使用次数，在"主动释放自己的技能"时仍然会触发自己的行动节点（见 02-核心概念 硬控制章节）

### 1.3 编队

`G.team = ['pro', 'xiayang', 'luyouyou']`（初始值；玩家可以在编队界面切换）

- 编队调整**只能在编队界面进行**（iconbar 编队按钮，非剧情/战斗态下可打开）
- 角色页面**不能**调整编队（角色页面只看数值、羁绊、天赋进度、预留多形态技能形态选择）
- 每有 1 个角色编入编队 → 技能组额外解锁 1 个槽位
- 天赋技能：**只要编入编队就全部生效**，无需加入技能组

### 1.4 角色羁绊

角色之间有羁绊等级（好感度系统）：
- 赠予队友永久物品中的赠品类（如 `caiyunPendant` 裁云挂件）+10 好感
- 特定事件选项可以 + 好感
- 聊天成功可以 + 好感
- 好感度影响：羁绊等级高时，连携窗口出现概率提升、队友主动释放技能的 AI 优先级更高（未来规划）

## 二、角色属性

### 2.1 主角完整属性

| 属性 | 基础 vs 局内 | 范围 | 备注 |
|---|---|---|---|
| 生命值 HP | 当前值 / 最大值 | 0 ~ maxHp | 归零战斗失败 / 全局失败 |
| 最大生命值 maxHp | 基础 + 永久物品 + 永久天赋 + 战斗内 buff | — | 提升时默认回复等额 HP；降低时默认不扣 HP（除非超出） |
| 攻击力 atk | 基础 + 永久物品 + 永久天赋 + 战斗内 buff | — | 战斗中提到"攻击力"默认指局内攻击力 |
| 防御力 def | 基础 + 永久物品 + 永久天赋 + 战斗内 buff | — | 每回合开始获得等同 100% 局内防御的护盾 |
| 暴击率 critRate | 基础 + 永久物品 + 永久天赋 + 战斗内 buff | 0% ~ 100% | 暴击时最终伤害翻倍（规格明确时再说） |
| 速度 speed | 基础 | 0 ~ 999 | 只影响逃跑概率 |
| 闪避率 evade | 基础 + buff | 0% ~ 100% | 规格预留；可能未实现 |
| 行动力 actionPoint | 每日 3 + 帐篷永久 + 永久 buff | — | 探索用，战斗无用 |
| 健康 health | 0 ~ 99 | — | 战斗失败扣；归零全局失败 |

### 2.2 队友属性

队友简化显示：**攻击力、暴击率**（不需要 HP / 防御 / 速度 等）。

### 2.3 局内 / 基础的区别

- **基础**：角色永久自带的数值 + 永久物品加成（战斗开始前就确定）
- **局内**：基础 + 战斗中临时 buff 的实时数值
- 战斗中提到"攻击力"默认指**局内攻击力**
- 战斗结束时局内 buff 会被清除 → 局内数值回到基础值

## 三、技能系统

### 3.1 技能分类（总表）

| kind | 中文名 | 作用时机 | 手动触发 | 放入技能组 | 示例 |
|---|---|---|---|---|---|
| `active` | 主动技能 | 玩家操控阶段 | ✅ 必须手动点 / 快捷键 | ✅ | 拼命、燎原、碎光 |
| `auto` | 自动技能 | 自动技能阶段（玩家操控阶段结束后） | ❌ 玩家无法手动释放 | ✅ | 连打、自动援护 |
| `link` | 连携技能 | 任意时刻（有 2 秒窗口时） | ✅ 按 E 键 | ✅ | 燎原·连携、移形·连携 |
| `talent` | 天赋技能 | 编入编队时立即生效 | ❌ | ❌ 不占技能组 | 暴击、嗜血、起势、格挡、坚守、拼命 |

### 3.2 技能字段定义

```js
{
  id: 'pinming',                    // 唯一 id
  name: '拼命',                      // 显示名
  kind: 'active' | 'auto' | 'link' | 'talent',
  element: 'fire' | 'water' | ... | null,  // null 表示无元素
  type: 'physical' | 'elemental',
  range: {                          // 范围定义
    type: 'front1' | 'front2' | 'front3' | 'front6'
         | 'self' | 'self-area4' | 'frontArea3x3'
         | 'all',
    cells: [...]                    // 可选：显式列出格子偏移（相对于 owner 朝向/位置）
  },
  target: 'enemy' | 'ally' | 'self' | 'all',
  ruleTag: 'default' | 'careful' | 'indiscriminate',
  // ruleTag 对应索敌三条规则：
  //   default:   "对xx范围造成xx元素伤害"（范围所有地块+所有可攻击敌方实体）
  //   careful:   "对xx范围内的xx阵营的xx单位造成xx元素伤害"（严格按描述筛选）
  //   indiscriminate: "对xx范围内造成不分敌我的xx元素伤害"（范围所有地块+所有可攻击实体）
  
  mult: 1.5,                        // 伤害倍率
  formula: 'atk*1.5',               // 公式（简化字符串，供 resolveSkill 计算）
  
  cd: 3,                            // 默认冷却（回合数）；未声明默认 1
  
  // 连携专属
  trigger: string,                  // 专属前置条件字符串（如 'afterFireAttachUsed' / 'burningEnemyPresent'）
  
  // 天赋专属
  talentEffect: {...},              // 效果（战斗自动触发 / 探索自动触发）
  
  // 多形态技能预留
  forms: [...]                      // 数组：每个形态是一个独立技能定义
}
```

### 3.3 技能范围类型（`range.type`）

| type | 说明 | 可视化（↑ = 朝向） |
|---|---|---|
| `self` | 仅自身格 | `[P]` |
| `self-area4` | 自身 + 上下左右 4 格 | `.↑.`<br>`←P→`<br>`.↓.` |
| `front1` | 前方 1 格 | `.↑.`<br>`.P.`<br>`.F.` |
| `front2` | 前方 2 格 | `.↑.`<br>`.F.`（P 后面两个 F） |
| `front3` | 前方 3 格 | 直线 3 格 |
| `front6` | 前方 6 格 | 直线 6 格（远程） |
| `frontArea3x3` | 前方 3×3 方块 | 以朝向为轴的 3×3 |
| `selfArea3x3` | 自身 3×3 | 自身为中心的 3×3 |
| `all` | 全场 | — |

所有范围在计算时会**先按 owner 朝向 + owner 坐标算出所有格子**，然后跳过 `terrain==='void'` 的外部地块（这些地块不受任何附着/伤害）。

### 3.4 索敌三条规则的代码映射

```
ruleTag = 'default':          // 技能描述："对 xx 范围造成 xx 元素伤害"
  attachCells = 范围内所有 terrain !== 'void' 的地块
  targetEntities = 范围内所有 entityId !== null 且 faction === 'enemy' 的实体

ruleTag = 'careful':          // 技能描述："对 xx 范围内的 xx 阵营的 xx 单位造成 xx 元素伤害"
  // 由 skill.target 字段 + 可选的 targetFaction 字段精确筛选
  attachCells = 只对 targetEntities 所在的地块施加
  targetEntities = 精确按描述筛选

ruleTag = 'indiscriminate':   // 技能描述："对 xx 范围内造成不分敌我的 xx 元素伤害"
  attachCells = 范围内所有 terrain !== 'void' 的地块
  targetEntities = 范围内所有 entityId !== null 且 faction  !== 'neutral' 的实体
  // （规格说"包括自身、我方、中立、敌方"——要注意中立默认不会被我方主动技能打到；
  //  但 indiscriminate 规则里中立也会被打到）
```

## 四、天赋技能

### 4.1 天赋的特殊规则

- **编入编队即自动生效**，不需要加入技能组
- 永远**不可被驱散**
- 不受**任何硬控制效果**影响（冻结的主角其天赋仍然触发）
- 无论探索中还是战斗中**都生效**（战斗中天赋触发战斗 buff；探索中天赋触发探索效果）
- 属于角色**永久能力**，与角色本身绑定

### 4.2 主角天赋总表（示例，不是完整数据）

| 天赋 id | 名字 | 效果 | 叠加方式 |
|---|---|---|---|
| `crit` | 暴击 | 攻击力基础 +5%、暴击率基础 +5% | 每级 +5% |
| `bloodlust` | 嗜血 | 暴击时回复 5% HP | 每级 +2% |
| `momentum` | 起势 | 战斗开始第一回合攻击力 +20% | 每级 +10% |
| `block` | 格挡 | 每回合开始额外获得 10 点护盾 | 每级 +5 点 |
| `persist` | 坚守 | 每回合开始额外获得 5 点护盾 | 每级 +3 点 |
| `desperation` | 拼命 | HP < 30% 时攻击力 +30% | 每级 +15% |

**永久物品对天赋的加成**（物品 `club` 木棒 → 主角【天赋·暴击】提升 1 级）：

```js
// combat.js 的 _applyItemBuffs() 内部：
const clubN = G.inventory.club || 0
getChar('pro').talents.crit += clubN   // 天赋等级直接 + 叠加数
```

### 4.3 队友天赋（示例）

| 角色 | 天赋 | 效果 |
|---|---|---|
| 夏阳 | `dance`（蹁跹） | 移动后回复 hv 点生命（hv 按羁绊等级） |
| 夏阳 | — | 战斗中天赋（待设计） |
| 陆悠悠 | `heal`（治疗） | 战斗中每回合对主角回复 HP |

## 五、技能组（SkillGroup）

### 5.1 规格总览

**技能组 = 整个编队共用的一套技能槽位**。**唯一入口是编队界面**。

#### 槽位生成公式

```
槽位数 = min(10, 4 + team.length)
```

| team.length | 槽位数 |
|---|---|
| 1（只有主角） | 5 |
| 2（主角+1队友） | 6 |
| 3（主角+2队友） | 7 |

槽 1~4 允许放 kind ∈ {active, auto, link}；槽 5+ 只能放 kind ∈ {auto, link}（active 会被自动重排序挪回前 4 槽内）。

**主动技能总数硬上限 4 个**—— 整条技能组里所有 active kind 的技能加起来不能超过 4。

#### 自动重排序（只处理"大排序"，不打乱玩家手动同类内部顺序）

```
[ active 块（玩家手动拖拽后的内部顺序保持稳定） ]
[ auto   块（玩家手动拖拽后的内部顺序保持稳定） ]
[ link   块（玩家手动拖拽后的内部顺序保持稳定） ]

重排序触发时机：添加一个新技能 / 卸下一个技能 / 切换编队人员
重排序后自动重新编号 slot 1, 2, 3, …
```

#### 禁止添加的情况

1. **槽位已满**（`group.length >= min(10, 4 + team.length)`） → UI 红色提示
2. **主动技能总数已达 4** → UI 提示"主动技能最多同时编入 4 个"
3. **技能 id 重复**（同一个角色的同一个技能已经在技能组里了）
4. **技能所属角色不在当前编队** → UI 提示"该角色不在编队中"

#### 二击切换交互（统一方式）

**没有 ❌ 按钮**。所有加/卸/选 全靠点击：

| 点击场景 | 第 1 次点击 | 第 2 次点击（同一个 tile） |
|---|---|---|
| 在技能库（角色页面里） | 选中，右侧技能描述区显示详情 | 切换状态：没加入技能组 → 加入；已加入 → 卸下 |
| 在技能组槽位里 | 选中，右侧技能描述区显示详情 | 切换状态：卸下 |

**拖拽**：
- **允许**：同类技能之间拖拽（active 块里内部可以调顺序、auto 块内部可以调）
- **禁止**：不同类技能拖拽（active 不能拖进 auto 块，拖过去会被自动重排序拉回）
- 拖拽释放后自动重编号 slot

#### 同类内部排序（玩家手动）

玩家可以在**同一 kind 的块内部**自由拖拽排序，这个排序在自动重排序之后会被**稳定保留**。比如玩家把"夏阳的燎原·连携"从 skillGroup[3] 拖到 skillGroup[1]（在 auto 块内部），自动重排序后它仍然是 auto 块里的第 1 个。

## 六、物品系统

### 6.1 四类物品

| 分类 | 标志 | 叠加方式 | 可出售 | 战斗中能用 | 例子 |
|---|---|---|---|---|---|
| **消耗品** | 无 permanent:true | 同 key 数量累加（fruit 可叠加 99） | ✅ 部分 | ❌（战斗中打不开背包） | 野果、生肉、草药、亚麻、木材、蓝晶 |
| **永久物品** | permanent:true | 同一 key 可叠加（club 可以叠多个） | ❌ 不可出售 | ✅ 部分（战斗外自动触发） | 木棒、布衣、匕首、盔甲、帐篷、枯木新枝、幸运硬币、裁云挂件、魔法扫帚 |
| **载具** | vehicle:true 或 VEHICLES 表里存在 | 同种载具独立（broom 可 push 多个 {uses:2} 到 G.vehicles[]） | ❌ | ✅ 部分（exploreOnly 标记的只能探索用） | 魔法扫帚、地龙、马车、蘑菇弹、飞毯 |
| **杂物** | （无显式标志；语义判断） | 不应该叠加（纯文学性） | ❌ 不应该出售 | ❌ | 破碎的风铃零件、一封未寄出的家书、奇怪的石头 |
| **任务道具** | （无显式标志；语义判断） | 不应该叠加（剧情专用） | ❌ | ❌ | 某个 NPC 给的"关键碎片"、"密封的信封" |

### 6.2 永久物品的三种子类型

| 子类型 | 效果时机 | 例子 |
|---|---|---|
| **天赋强化类** | 战斗中自动结算（`_applyItemBuffs` 里） | club → 暴击天赋等级+1；dagger → 嗜血天赋等级+1 |
| **探索辅助类** | 睡觉时触发 / 每次移动后触发 / 每日自动触发 | tent → 行动力上限+1；deadwoodSprout → 每次移动回 12 HP；goodCard → 睡觉时 +1 金币 |
| **战斗胜利类** | 战斗结算时判定 | luckyCoin → 2%（每层 +2%）概率额外获得 1 次奖励 |

### 6.3 消耗品

**只在探索、剧情、事件中使用**。战斗中打不开背包、不能使用消耗品。

| 子类型 | 用途 | 触发场景 |
|---|---|---|
| 食物（野果/生肉/熟肉） | 回复 HP | 探索中打开背包 → 点「使用」按钮 |
| 合成原料（木材/亚麻/蓝晶/蓝晶粉） | 合成台 craft.js 的原料 | 探索中打开合成台 |
| 赠品类（熟肉/草药/裁云挂件） | 给队友 + 好感 | 探索中与队友对话时打开赠予菜单 |

**永久物品 `campfire`（篝火）**：食用食物后使某类食物的回复量**永久增加**（果子+1、生肉+2、熟肉+4）。效果永久生效，叠加可叠加。

### 6.4 载具系统

详见 [04-探索与地图](04-探索与地图.md) §三。核心语义：
- 徒步跋涉 / 疾行 **严格不属于载具**（虽然在 VEHICLES 表里）
- 狭义载具：地龙、蘑菇弹、马车、魔法扫帚、飞毯、巧遇
- 载具获得方式：启程任务奖励、事件购买、合成、赠予
- 载具 uses：每次使用消耗 1 次；耗尽自动切回徒步跋涉

### 6.5 杂物 = 纯文学性

杂物：与任何任务/合成/赠送都无关的纯文学性、纯剧情彩蛋类物品。
- 不可合成、不可出售、不可吃、不可赠予
- 只用来让玩家记住某个 NPC、某个事件、某个地点
- 可以有 lore 描述（"摸起来冰凉"、"一封未寄出的家书"）
- 永久存在于背包里直到被剧情处理

### 6.6 任务道具

任务道具只在**事件流程中被消耗**。玩家不能主动使用、不能出售、不能合成。
- 例子：支线"帮猎人找回 3 块狼皮"里的"狼皮"（收集目标物，但不是消耗品）
- 例子："送信任务"里的"密封的信封"（只能在事件流程里交给指定 NPC）

### 6.7 金币

- 全局下限 0，上限 999
- 规格预留：特殊方式可以让下限变为 -999（目前没有实现）
- 获得方式：战斗胜利奖励、空地搜索小概率、睡觉 goodCard 触发、出售可售物品
- 消耗方式：商店购买、事件选项（付费）、某些合成成本
