# 05 · 角色 · 技能 · 物品

> 阅读前置：[02-核心概念](02-核心概念.md)（技能、阵营、技能组、永久物品等术语）。

## 一、角色总览

当前游戏 3 个角色：主角（pro）、夏阳（xiayang）、陆悠悠（luyouyou）。未来可以扩展。

### 1.1 主角（pro）

- **阵营**：我方
- **有生命值系统**（HP / maxHp），归零则战斗失败 / 全局失败
- **有速度属性**（只影响逃跑概率）
- **有行动力属性**（探索时移动消耗；睡觉回满）
- **有健康 / 心理压力属性**（探索时扣；归零全局失败）
- **位置 + 朝向 = 绑定主角自己**（主角就是主角）

### 1.2 队友（xiayang / luyouyou）

- **阵营**：我方
- **没有生命值系统**（不会死亡）
- **没有速度属性**
- **位置 + 朝向 = 永远绑定主角**（主角到哪、队友跟到哪；主角朝向哪、队友朝向哪）
- **没有独立行动节点触发时机**？—— 不，队友有自己的技能使用次数，在"主动释放自己的技能"时仍然会触发自己的行动节点（见 02-核心概念 硬控制章节）

### 1.3 编队

`G.team = ['pro', 'xiayang', 'luyouyou']`（初始值；玩家可以在编队界面切换）

- 编队调整**只能在编队界面进行**（iconbar 编队按钮，非剧情/战斗态下可打开）
- 角色页面**不能**调整编队（角色页面只看数值、羁绊、天赋进度、预留多形态技能形态选择）
- 每有 1 个角色编入编队 → 技能组额外解锁 1 个槽位
- 天赋技能：**只要编入编队就全部生效**，无需加入技能组

### 1.4 好感度与羁绊等级

**只有非主角角色（队友）有好感度。主角没有好感度，也没有羁绊等级。**

- 好感度：每个队友独立的一个数值（整数，可升可降）
- 羁绊等级：**该队友的"解锁等级"，每累计好感度达到 10、20、30、40、…（整十点）时，羁绊等级上升 1 级**
  - 至多 10 级（对应好感度最高 100）
  - **羁绊等级上升后不会再下降**（即使后续好感度掉到某个整十点以下，羁绊等级仍保持原来的数值——"只升不降"）
  - 羁绊等级的直接用途：**依次解锁该队友的各个技能**（具体解锁顺序由游戏设计决定，规格不强制）。要把新队友编入编队，通常需要先提升到最低可用的羁绊等级（比如 1 级才能上场）

好感度变化来源（仅为总述，具体物品/事件在各物品和事件的定义里）：
- 赠予队友特定物品（如熟肉给夏阳、草药给陆悠悠）→ +N 好感
- 特定事件选项 → ±N 好感
- 剧情分支选择 → ±N 好感
- 某些永久物品（如 `windChime`）提升与队友聊天时的成功概率 → 更高好感

### 1.5 角色页面

角色页面是**非剧情 / 战斗**态下打开的界面，承载：

| 板块 | 内容 |
|---|---|
| 角色卡一行 | 编队中各角色的名字 + 头像 + 羁绊等级 + 好感度数值 |
| 数值面板 | 当前选中角色的完整属性（主角全显、队友简化） |
| 天赋列表 | 天赋技能（编入编队时自动激活），点击弹出完整效果 |
| **交互页面（必须保留）** | 与选中角色进行互动的功能入口（提升好感度的主要方式：赠予物品、聊天、邀请等）。**这块不能删**，是提升队友好感度的核心途径 |
| 多形态技能形态选择（预留） | 只有拥有多形态技能的角色才显示（目前没有） |

**规格强制**：角色页面**不能**调整编队（编队在编队界面里调）、**不能**调整技能组（技能组在编队界面里调）、**不能**执行"有实际影响"的战斗相关操作（如修改技能形态）。

但角色页面在**剧情中 / 战斗中**仍然可以打开（见 [06-UI·交互](06-UI·交互.md) §五 · iconbar 禁用规则），只是此时**禁用任何有实际影响的操作**（禁用赠予、禁用修改形态、禁用与角色交互提升好感等）。只能查看。

## 二、角色属性

### 2.1 主角完整属性

| 属性 | 基础 vs 局内 | 范围 | 备注 |
|---|---|---|---|
| 生命值 HP | 当前值 / 最大值 | 0 ~ maxHp | 归零战斗失败 / 全局失败 |
| 最大生命值 maxHp | 基础 + 永久物品 + 永久天赋 + 战斗内 buff | — | 提升时默认回复等额 HP；降低时默认不扣 HP（除非超出） |
| 攻击力 atk | 基础 + 永久物品 + 永久天赋 + 战斗内 buff | — | 战斗中提到"攻击力"默认指局内攻击力 |
| 防御力 def | 基础 + 永久物品 + 永久天赋 + 战斗内 buff | — | 每回合开始获得等同 100% 局内防御的护盾 |
| 暴击率 critRate | 基础 + 永久物品 + 战斗内 buff | 0% ~ 100% | 暴击时最终伤害翻倍（规格明确时再说） |
| 速度 speed | 基础 | 0 ~ 999 | 只影响逃跑概率 |
| 闪避率 evade | 基础 + buff | 0% ~ 100% | 规格预留；可能未实现 |
| 行动力 actionPoint | 每日 3 + 帐篷永久 + 永久 buff | — | 探索用，战斗无用 |
| 健康 health | 0 ~ 99 | — | 战斗失败扣；归零全局失败 |

### 2.2 队友属性

队友简化显示：**攻击力、暴击率**（不需要 HP / 防御 / 速度 等）。

### 2.3 局内 / 基础的区别

- **基础**：角色永久自带的数值 + 永久物品加成（战斗开始前就确定）
- **局内**：基础 + 战斗中临时 buff 的实时数值
- 战斗中提到"攻击力"默认指**局内攻击力**
- 战斗结束时局内 buff 会被清除 → 局内数值回到基础值

## 三、技能系统

### 3.1 技能分类（总表）

| kind | 中文名 | 作用时机 | 手动触发 | 放入技能组 | 示例 |
|---|---|---|---|---|---|
| `active` | 主动技能 | 玩家操控阶段 | ✅ 必须手动点 / 快捷键 | ✅ | 拼命、燎原、碎光 |
| `auto` | 自动技能 | 自动技能阶段（玩家操控阶段结束后） | ❌ 玩家无法手动释放 | ✅ | 连打、自动援护 |
| `link` | 连携技能 | 任意时刻（有 2 秒窗口时） | ✅ 按 E 键 | ✅ | 燎原·连携、移形·连携 |
| `talent` | 天赋技能 | 编入编队时立即生效 | ❌ | ❌ 不占技能组 | 角色自身永久能力（如夏阳·蹁跹、陆悠悠·治疗、队友·技能解锁等） |

### 3.2 技能字段定义

```js
{
  id: 'pinming',                    // 唯一 id
  name: '拼命',                      // 显示名
  kind: 'active' | 'auto' | 'link' | 'talent',
  element: 'fire' | 'water' | ... | null,  // null 表示无元素
  type: 'physical' | 'elemental',
  range: {                          // 范围定义
    type: 'front1' | 'front2' | 'front3' | 'front6'
         | 'self' | 'self-area4' | 'frontArea3x3'
         | 'all',
    cells: [...]                    // 可选：显式列出格子偏移（相对于 owner 朝向/位置）
  },
  target: 'enemy' | 'ally' | 'self' | 'all',
  ruleTag: 'default' | 'careful' | 'indiscriminate',
  // ruleTag 对应索敌三条规则：
  //   default:   "对xx范围造成xx元素伤害"（范围所有地块+所有可攻击敌方实体）
  //   careful:   "对xx范围内的xx阵营的xx单位造成xx元素伤害"（严格按描述筛选）
  //   indiscriminate: "对xx范围内造成不分敌我的xx元素伤害"（范围所有地块+所有可攻击实体）
  
  mult: 1.5,                        // 伤害倍率
  formula: 'atk*1.5',               // 公式（简化字符串，供 resolveSkill 计算）
  
  cd: 3,                            // 默认冷却（回合数）；未声明默认 1
  
  // 连携专属
  trigger: string,                  // 专属前置条件字符串（如 'afterFireAttachUsed' / 'burningEnemyPresent'）
  
  // 天赋专属
  talentEffect: {...},              // 效果（战斗自动触发 / 探索自动触发）
  
  // 多形态技能预留
  forms: [...]                      // 数组：每个形态是一个独立技能定义
}
```

### 3.3 技能范围类型（`range.type`）

| type | 说明 | 可视化（↑ = 朝向） |
|---|---|---|
| `self` | 仅自身格 | `[P]` |
| `self-area4` | 自身 + 上下左右 4 格 | `.↑.`<br>`←P→`<br>`.↓.` |
| `front1` | 前方 1 格 | `.↑.`<br>`.P.`<br>`.F.` |
| `front2` | 前方 2 格 | `.↑.`<br>`.F.`（P 后面两个 F） |
| `front3` | 前方 3 格 | 直线 3 格 |
| `front6` | 前方 6 格 | 直线 6 格（远程） |
| `frontArea3x3` | 前方 3×3 方块 | 以朝向为轴的 3×3 |
| `selfArea3x3` | 自身 3×3 | 自身为中心的 3×3 |
| `all` | 全场 | — |

所有范围在计算时会**先按 owner 朝向 + owner 坐标算出所有格子**，然后跳过 `terrain==='void'` 的外部地块（这些地块不受任何附着/伤害）。

### 3.4 索敌三条规则的代码映射

```
ruleTag = 'default':          // 技能描述："对 xx 范围造成 xx 元素伤害"
  attachCells = 范围内所有 terrain !== 'void' 的地块
  targetEntities = 范围内所有 entities.length > 0 且 faction === 'enemy' 的实体（同格多个实体全部命中）

ruleTag = 'careful':          // 技能描述："对 xx 范围内的 xx 阵营的 xx 单位造成 xx 元素伤害"
  // 由 skill.target 字段 + 可选的 targetFaction 字段精确筛选
  attachCells = 只对 targetEntities 所在的地块施加
  targetEntities = 精确按描述筛选

ruleTag = 'indiscriminate':   // 技能描述："对 xx 范围内造成不分敌我的 xx 元素伤害"
  attachCells = 范围内所有 terrain !== 'void' 的地块
  targetEntities = 范围内所有 entities.length > 0 且 faction  !== 'neutral' 的实体（同格多个实体全部命中）
  // （规格说"包括自身、我方、中立、敌方"——要注意中立默认不会被我方主动技能打到；
  //  但 indiscriminate 规则里中立也会被打到）
```

## 四、天赋技能（完整版）

### 4.1 天赋的特殊规则

- **编入编队即自动生效**，不需要加入技能组
- 永远**不可被驱散**
- 不受**任何硬控制效果**影响（冻结的主角其天赋仍然触发）
- 无论探索中还是战斗中**都生效**（战斗中天赋触发战斗 buff；探索中天赋触发探索效果）
- 属于角色**永久能力**，与角色本身绑定

### 4.4 陆悠悠（luyouyou）—— 风元素 · 天赋 + 技能

| 主动 | `soar` | 腾空击 | 对自身所在地块施加风元素附着，对周围 9 格的敌人造成相当于 100% 攻击力的风元素伤害 | 3 回合 |
| 连携 | `weakPoint` | 弱点击破 | 3 格距离内有敌人正在【蓄力】时可以使用。对该敌人造成相当于 130% 攻击力的物理伤害、施加持续 3 回合的【束缚】。本次攻击暴击率 +100% | 4 回合 |
| 连携 | `eye` | 风暴眼 | 我方单位累计触发 4 次扩散反应后可以使用。锁定 2 格内的随机 1 名敌人，对其 2 格距离内的所有敌人造成相当于 80% 攻击力的风元素伤害。随后清空计数 | — |
| 连携 | `windRise` | 风起 | 我方单位对敌人所在地块施加火/水/雷/冰附着时可以使用。对该敌人（至多 1 名）造成相当于 30% 攻击力的风元素伤害、施加持续 3 回合的 35%【易伤】 | 5 回合 |

### 5.1 规格总览

**技能组 = 整个编队共用的一套技能槽位**。**唯一入口是编队界面**。

#### 槽位生成公式

```
槽位数 = min(10, 4 + team.length)
```

| team.length | 槽位数 |
|---|---|
| 1（只有主角） | 5 |
| 2（主角+1队友） | 6 |
| 3（主角+2队友） | 7 |

槽 1~4 允许放 kind ∈ {active, auto, link}；槽 5+ 只能放 kind ∈ {auto, link}（active 会被自动重排序挪回前 4 槽内）。

**主动技能总数硬上限 4 个**—— 整条技能组里所有 active kind 的技能加起来不能超过 4。

#### 自动重排序（只处理"大排序"，不打乱玩家手动同类内部顺序）

```
[ active 块（玩家手动拖拽后的内部顺序保持稳定） ]
[ auto   块（玩家手动拖拽后的内部顺序保持稳定） ]
[ link   块（玩家手动拖拽后的内部顺序保持稳定） ]

重排序触发时机：添加一个新技能 / 卸下一个技能 / 切换编队人员
重排序后自动重新编号 slot 1, 2, 3, …
```

#### 禁止添加的情况

1. **槽位已满**（`group.length >= min(10, 4 + team.length)`） → UI 红色提示
2. **主动技能总数已达 4** → UI 提示"主动技能最多同时编入 4 个"
3. **技能 id 重复**（同一个角色的同一个技能已经在技能组里了）
4. **技能所属角色不在当前编队** → UI 提示"该角色不在编队中"

#### 二击切换交互（统一方式）

**没有 ❌ 按钮**。所有加/卸/选 全靠点击：

| 点击场景 | 第 1 次点击 | 第 2 次点击（同一个 tile） |
|---|---|---|
| 在技能库（角色页面里） | 选中，右侧技能描述区显示详情 | 切换状态：没加入技能组 → 加入；已加入 → 卸下 |
| 在技能组槽位里 | 选中，右侧技能描述区显示详情 | 切换状态：卸下 |

**拖拽**：
- **允许**：同类技能之间拖拽（active 块里内部可以调顺序、auto 块内部可以调）
- **禁止**：不同类技能拖拽（active 不能拖进 auto 块，拖过去会被自动重排序拉回）
- 拖拽释放后自动重编号 slot

#### 同类内部排序（玩家手动）

玩家可以在**同一 kind 的块内部**自由拖拽排序，这个排序在自动重排序之后会被**稳定保留**。比如玩家把"夏阳的燎原·连携"从 skillGroup[3] 拖到 skillGroup[1]（在 auto 块内部），自动重排序后它仍然是 auto 块里的第 1 个。

## 六、物品系统

### 6.1 四类物品

| 分类 | 标志 | 可出售 | 战斗中能用 | 例子 |
|---|---|---|---|---|
| **消耗品** | 无 permanent:true | ✅ 部分 | ❌（战斗中打不开背包） | 野果、生肉、草药、亚麻、木材、蓝晶 |
| **永久物品** | permanent:true | ❌ 不可出售 | ✅ 部分（战斗外自动触发） | 木棒、布衣、匕首、盔甲、帐篷、枯木新枝、幸运硬币、裁云挂件、魔法扫帚 |
| **载具** | vehicle:true 或 VEHICLES 表里存在 | ❌ | ✅ 部分（exploreOnly 标记的只能探索用） | 魔法扫帚、地龙、马车、蘑菇弹、飞毯 |
| **杂物** | （无显式标志；语义判断） | ❌ 不应该出售 | ❌ | 破碎的风铃零件、一封未寄出的家书、奇怪的石头 |
| **任务道具** | （无显式标志；语义判断） | ❌ | ❌ | 某个 NPC 给的"关键碎片"、"密封的信封" |

### 重要：物品叠加规则**不由分类决定，由每个物品自己决定**

上表之前的版本曾列过"叠加方式"一列，那是错误的——**物品是否可叠加、上限是多少，完全由该物品自己的 data 字段声明**，与它属于哪一类（消耗品、永久物品、杂物、任务道具）**完全无关**：

```js
// 示例：每个物品独立声明自己的叠加规则
fruit:     { name:'野果', stackable:true,  stackMax:99,  ... }
caiyunPendant: { name:'裁云挂件', stackable:false, ... }  // 虽然是"赠品类消耗品"，但不可叠加
club:      { name:'木棒', stackable:true,  ... }
brokenBell:{ name:'破碎的风铃零件', stackable:false, ... } // 杂物，不可叠加
```

- 载具是特殊情况：载具的"叠加"机制不是 `G.inventory[key] += 1`，而是**向 `G.vehicles[]` 数组 push 一个新的 `{key:'broom', uses:2}` 对象**——同一个 key 的载具可以有多个独立对象（每个对象有独立的 uses 计数）。这是载具特有的存储方式

### 6.2 永久物品的三种子类型

| 子类型 | 效果时机 | 例子 |
|---|---|---|
| **主角属性直接加成类** | 战斗中自动结算（`_applyItemBuffs` 里直接按物品数量算数值） | club → 攻击+10/暴击率+3%；dagger → 攻击+20/暴击吸血；ironSword → 攻击+30/第一回合伤害+4%；cloth → 生命+50/2%格挡；leather → 生命+50/3%免死；armor → 生命+50/防御+20/2%格挡+3%免死 |
| **探索辅助类** | 睡觉时触发 / 每次移动后触发 / 每日自动触发 | tent → 行动力上限+1；deadwoodSprout → 每次移动回 12 HP；goodCard → 睡觉时 +1 金币 |
| **战斗胜利类** | 战斗结算时判定 | luckyCoin → 2%（每层 +2%）概率额外获得 1 次奖励 |

### 6.3 消耗品

**只在探索、剧情、事件中使用**。战斗中打不开背包、不能使用消耗品。

| 子类型 | 用途 | 触发场景 |
|---|---|---|
| 食物（野果/生肉/熟肉） | 回复 HP | 探索中打开背包 → 点「使用」按钮 |
| 合成原料（木材/亚麻/蓝晶/蓝晶粉） | 合成台 craft.js 的原料 | 探索中打开合成台 |
| 赠品类（熟肉/草药/裁云挂件） | 给队友 + 好感 | 探索中与队友对话时打开赠予菜单 |

**永久物品 `campfire`（篝火）**：食用食物后使某类食物的回复量**永久增加**（果子+1、生肉+2、熟肉+4）。效果永久生效，叠加可叠加。

### 6.4 载具系统

详见 [04-探索与地图](04-探索与地图.md) §三。核心语义：
- 徒步跋涉 / 疾行 **严格不属于载具**（虽然在 VEHICLES 表里）
- 狭义载具：地龙、蘑菇弹、马车、魔法扫帚、飞毯、巧遇
- 载具获得方式：启程任务奖励、事件购买、合成、赠予
- 载具 uses：每次使用消耗 1 次；耗尽自动切回徒步跋涉

### 6.5 杂物 = 纯文学性

杂物：与任何任务/合成/赠送都无关的纯文学性、纯剧情彩蛋类物品。
- 不可合成、不可出售、不可吃、不可赠予
- 只用来让玩家记住某个 NPC、某个事件、某个地点
- 可以有 lore 描述（"摸起来冰凉"、"一封未寄出的家书"）
- 永久存在于背包里直到被剧情处理

### 6.6 任务道具

任务道具只在**事件流程中被消耗**。玩家不能主动使用、不能出售、不能合成。
- 例子：支线"帮猎人找回 3 块狼皮"里的"狼皮"（收集目标物，但不是消耗品）
- 例子："送信任务"里的"密封的信封"（只能在事件流程里交给指定 NPC）

### 6.7 金币

- 全局下限 0，上限 999
- 规格预留：特殊方式可以让下限变为 -999（目前没有实现）
- 获得方式：战斗胜利奖励、空地搜索小概率、睡觉 goodCard 触发、出售可售物品
- 消耗方式：商店购买、事件选项（付费）、某些合成成本

## 八、敌人数据（史莱姆系）

> 本节定义战斗中最常见的敌人——七种元素史莱姆的完整规格。规格以设计文档为准，代码实现与本节冲突时以本节为准。

### 8.1 通用基础数据（七种史莱姆完全相同）

| 属性 | 值 |
|---|---|
| faction | `'enemy'` |
| 攻击力 atk | 10 |
| 防御力 def | 0（岩史莱姆例外，见天赋） |
| 最大生命值 maxHp | 100 |
| 速度 speed | 4 |
| 元素抗性 | 全部 0 |
| 默认碰撞伤害 | 攻击力 100% = 10 物理伤害（规格 §二·五碰撞伤害规则） |

### 8.2 通用天赋（七种史莱姆完全相同）

| 天赋 | 效果 |
|---|---|
| **新手之友** | 前 12 天（day <= 12），最大生命值 -60（即实际 HP 40） |
| **X 元素亲和**（X = 草 / 火 / 水 / 雷 / 冰 / 风 / 岩） | 免疫本元素伤害。移动后为所在地块施加本元素附着 |

额外免疫规则：**冰史莱姆额外免疫冻结**；**雷史莱姆额外免疫感电**。

### 8.3 通用移动：蹦蹦跳跳

以顺时针方向沿回字形外圈前进 1 格。受到来自我方的伤害时，切换后续前进方向为伤害来源所在的方向（判定为：把回字形外圈视为一条闭合环路，比较敌人沿顺时针走到主角位置的距离 vs 沿逆时针走到主角位置的距离，距离较短的那个方向即为切换后的前进方向）。

备注：
- 回字形外圈的顺时针 / 逆时针坐标方向定义见 [04-探索与地图 §一·七](04-探索与地图.md)
- 攻击 / 辅助类技能期间**默认不移动**。若有可边放技能边移动的特殊技能，会单独说明
- 默认所有敌人有碰撞伤害。没有的用户会特殊说明

### 8.4 各史莱姆独有技能 / 天赋

#### 草史莱姆（元素亲和：草）

**攻击·破土而出**：瞬移到最近的一名我方单位周围 4 格随机 1 格，然后对周围 4 格造成相当于攻击力 75% 的草元素伤害。

#### 火史莱姆（元素亲和：火）

**天赋·自爆**：死亡后，在原地留下"即将爆炸的火史莱姆"（视为单位，但**不算敌人**）。即将爆炸的火史莱姆会在 2 个回合后爆炸，对周围 9 格造成不分敌我的相当于火史莱姆 120% 基础攻击力的火元素伤害。

备注：如果场上敌人已经被全部消灭，则无视即将爆炸的火史莱姆，直接结算战斗胜利。战斗结束后即将爆炸的火史莱姆也会按照正常流程被清除。

#### 水史莱姆（元素亲和：水）

**辅助·水泡**：对目标当前所在位置投掷水泡。水史莱姆的下一个回合开始时，水泡落下，"禁锢"该格的单位 2 回合。冷却：4 回合。

备注：水泡可以使用时优先使用水泡。使用水泡后本回合不移动。水泡使用后**立即进入冷却**，无需等到水泡落下。当我方移动离开当前位置后，水泡还是会落在原来的位置（会打空，无效果）。若原来的位置恰好有新的单位移动过来，则对这个单位触发效果（无论敌我）。如果是主角受到控制类效果，则队友不受影响。"禁锢"是词条，技能描述 UI 按词条形式显示。

#### 雷史莱姆（元素亲和：雷）

**天赋·导电**：每回合结束时，有 10% 概率对周围 5 格造成不分敌我的相当于 40% 攻击力的雷元素伤害。

备注：导电伤害不分敌我（但雷史莱姆自己免于雷元素伤害）。队友和主角视为在同一格，因为队友没有生命值所以不会受到伤害，但是附着还是会受到的，也可以触发元素反应（只吃效果类，不吃伤害）。

#### 冰史莱姆（元素亲和：冰；额外免疫：冻结）

**攻击·冰雾**：向前方 3 格所有我方单位喷射冰雾，造成相当于攻击力 80% 的冰元素伤害。该攻击**持续 2 回合**，期间无法移动或转向或使用其他攻击。冷却时间：5 回合。

备注：攻击持续 2 回合意味着从第一次开始使用起，连续两回合都放冰雾（两次造成伤害）。两回合后才进入冷却。

#### 风史莱姆（元素亲和：风）

**天赋·风旋**：被击败时，若战斗还未结束（场上还有其他敌人），将 2 格距离内的随机 1 格的所有单位传送至自身所在格；如果选中的目标是我方单位，还会额外造成相当于攻击力 40% 的风元素伤害。

备注：如果一场战斗中只剩它一个敌人，则它死后立即判定战斗胜利，它的这个天赋将不会生效。

#### 岩史莱姆（元素亲和：岩）

**天赋·岩盾**：最大生命值 -10%（即 maxHp 从 100 变成 90），防御力 +10。但每次被攻击（无论是否受伤）都会使自身防御力 -1。

备注：防御力允许在计算过程中超出范围，但最终结算时将数值调整为 0 到 99999 范围之间（clamp）。

### 8.5 敌人战斗奖励与战败惩罚

| 项 | 通用规则 |
|---|---|
| 战斗奖励 | 由**战斗关卡**决定，不是由史莱姆个体决定。见 [03-战斗系统 §十二·敌人数据](03-战斗系统.md) |
| 战败健康减少 | 由**战斗关卡**决定，不是由史莱姆个体决定。敌人本身不扣健康，是战斗失败才扣 |
