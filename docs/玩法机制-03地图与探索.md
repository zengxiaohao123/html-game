## 四、地图系统（js/map.js）

### 4.1 每日生成

- 每天开始时随机生成一张新图；当天固定；次日整图重生成（保留背包、天计数等全局状态）。
- **尺寸随天数渐进**（`mapSizeForDay`，参考值，另加随机波动 ±2，最小 4）：

```text
第1天=4x4   第20天=6x6   第50天=8x8   第100天=9x9   第150天=12x12
```

- **边框**：有效地图为内区 `n×n`，其外围再包一圈「地图外」（void）边框（总边长 n+2）。
- **保底连通**：生成后对「地面格」做连通性检查，若有不连通地块，会把相邻的山脉障碍转成地面作为“桥”，保证所有地面格连通。

### 4.2 每格内容分配（`rollCell`，内区每格独立）

| 内容 | 概率 | 说明 |
|---|---|---|
| 空地 empty | 30% | 进入后触发空地搜索 |
| 事件 event | 25% | 见 4.5 |
| 战斗 battle | 30% | 70% 普通(ordinary) / 30% 艰难(elite)；`boss` 目前仅固定事件被动 |
| 奖励 loot | 10% | 见 4.4 |
| 山脉 obstacle | 5% | 障碍，不可通行 |

- 出生点（`px,py`）从随机一个地面格生成；进入战斗/结束战斗都会把玩家**传送回进入战斗那一格**。

### 4.3 行动力（AP）与移动（js/explore.js）

- `actionPoint` 初始 5，当日上限 `apCap` 初始 5；`睡觉` 时恢复到上限。
- **移动**：只能移动到相邻一格（上下左右）；`行动力<1` 时无法移动，需睡觉进下一天。
- 目标为障碍/地图外 → 只改变朝向、**不消耗 AP**。
- 目标为地面格 → 消耗 1 AP，移动过去并**触发该格内容**；若为战斗格，登录后立即进入战斗。
- 载具：每次真实移动消耗 1 个已选载具次数，耗尽自动切回徒步（见 05）。

### 4.4 拾取 / 奖励（探索）

- **空地搜索**：进入空地触发；档位判定 50% 掉落 2 个同种资源，再 50% 掉落 2 个（可落空停止），至多 3 档=6 个。野外只产自然资源（木/亚麻/果/生肉）。
- **奖励格 Loot（宝箱）**：

```text
<40%      → 2 个随机资源
<90%      → 4 个随机资源
<97%      → 金币 4~10
<99.7%    → 木棒 或 布衣 ×1（永久物品，天赋+1）
其余      → 匕首 或 皮衣 ×1（永久物品，天赋+1）
```

### 4.5 事件（Event，一次性）

| 概率 | 事件 | 效果 |
|---|---|---|
| <28% | 商人遗落行囊 | 金币 +2~4 |
| <55% | 温泉歇脚 | 回复 15% +10 生命（满血则无实际效果） |
| <78% | 一场虚惊 | 健康 -1 |
| 其余 | 迷路旅人（二选一） | 慷慨相助→+5 金币 / 婉言谢绝→无事 |

### 4.6 区域

- `G.region` 当前恒为 `wild`（野外），探索资源池因此用自然资源。
- 🧩 **wild/city 区域切换**：`G.region` 未真正切换，“城市”侧资源（金币/空瓶子）与 UI 的区域显示均属**规划中**。
