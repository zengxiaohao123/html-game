## 一、当前实现状态（✅ 已上线）

### 核心循环
- 每天随机地图 → 探索收集/遇敌 → 回合战斗 → 睡觉进下一天（自动存档）。
- 健康归零 → 全局失败 Game Over（可读档/回主界面）。

### 探索
- 点击格子+「前往」或 WASD 移动；行动力 AP（初始/上限 5，帐篷可 +1）。
- 空地搜索（档位 50%，至多 6 资源）；奖励格新表。
- **随机事件系统（js/event.js）**：14 个事件（基础8个 + 新增：翻车现场、常乐·猜大小、一塌糊涂的菜园、废弃矿洞、道旁的修女、蘑菇迷境），等分出率；**多层级事件引擎**（`__continue` 标记支持无限嵌套选项推进，常乐事件4层状态机）；可交互选项（选中淡绿→确认金色→2s 淡出→结果回剧情区）；打字机剧情（约30字/秒、点击跳段/清空）；事件格进入即变空地、状态存 G.activeEvent 供读档重开；事件中禁用编队/商店/睡觉/合成，背包不可用，载具无实质效果。
- **翻车现场**：摔得人仰车翻的载具商人，4种载具选项（地龙/马车/魔法扫帚/魔法飞毯），选项2/3/4独立50%概率出现
- **常乐·猜大小**：12张牌抽3张判定大小，三种预测（稳一手/以小博大/帝王之征），帝王之征赢后进入**许愿三选一**（魔法秘籍/生存物资/远行装备），全押特殊赌博独立分支
- **道旁的修女**：初始成功率100%忏悔，成功后下次-5%（最低50%），失败不减
- **废弃矿洞**：60%矿石（铁块/紫水晶/钻石等概率）、30%塌方失40%HP、10%铁疙瘩战斗
- **蘑菇迷境**：10次独立随机效果（HP/金币/丢消耗品/得自然资源/基础攻击±5永久/最大HP±50永久/行动力±6）
- **新永久物品效果**：枯木新枝（回复12×N生命）、《愧怍》（空地失败后独立补偿判定）、幸运硬币（战斗每层+2%额外奖励概率）、风铃（待接入）
- **路线图**：新永久物品；持有时稀有动物格（带【稀有生物】天赋的敌人，如暴躁的熊）金标，进入消耗 1 张。
- 地图尺寸随天数递增+日波动，保底连通；地图外边框。

### 战斗
- 移动即结束我方回合；队友自动释放已选技能；敌人回合=移动+技能（意图回合初锁定，BFS 绕障逼近）。
- 状态系统、暴击（×2）、格挡/坚守、护盾(=防御)、逃跑系统、编队人数加成、元素亲和（史莱姆免疫）。
- **敌人共 20 个（技能+天赋全部接入）**：史莱姆系列（7个）+ 中二病/奇怪史莱姆/小小蛇/竹叶青/古树/猎犬/Pro/蓝羽/红羽镖客/熊/遗弃机关 + **铁疙瘩（ironClump，废弃矿洞10%战斗）**。
- **心理压力与抑郁**：psyStress 范围 -100~100，sleep() 时以 `max(0, psyStress)/100` 概率判定抑郁；抑郁持续一天，期间主角攻击/防御归零。
- **明心浆 buff**：合成/获得的明心浆可使用，持续一天：atk+25% / 受伤害-25%；sleep 时清除。
- **幸运硬币**：战斗中每层（每级？每层）增加 2% 概率获得额外奖励（`bonusRate`）。
- 多敌人依次行动（狗友/集群生效）；持续技能（冰雾/大清扫）`sustain` 连续使用后入冷却；【燃烧】【中毒】按回合刻蚀 2% / 层数；稀有熊跨天延续剩余生命（未击败不回复）。
- 史莱姆系列技能持续有效（撞击/破土而出/吐火/水泡/冰雾）。

### 系统
- 合成、载具、商店、背包、角色页、编队、任务、设置、8 槽存档读档、ESC 退回、词条/状态悬浮、地图缩放拖拽。
- **心理压力 HUD**：顶部显示心理压力值（-100~100），抑郁期间红色脉冲提示。
- **背包改版**：顶部四标签切换（消耗品 / 永久物品 / 杂物 / 任务道具）；右侧常驻 1/4 描述栏（点击物品显示详情 + 蓝色斜体 lore 段落）；关闭重开重置到「消耗品」。
- **魔法扫帚载具**（vehicle.js）：直线 3 格移动 / 共 2 次可用，保留原 carpet。
- **明心浆合成配方**：2 种合成路径，战斗中使用触发 atk+25%/受伤害-25% buff。
- **5 个启程任务挂钩**：心理健康（使用明心浆）、合成台（合成 N 件）、果腹（吃 N 个食物）、大口吃肉（吃生肉）、便捷出行（使用载具 N 次）、友谊的再开始（送礼）。
- **行动记录区**：无上限（仅战斗/睡觉时清除）。
- **任务系统**：接取钩子（首次遇讨伐熊事件才显示）；**自动接取提醒**（refreshHUD 里 questNotified 去重 log「📋 已接取XX任务」）；达标后**手动领取奖励**；奖励物品名称永远显示数量（如"紫水晶×1"）；备注不显示给玩家。
- **羁绊等级**：好感度 -999~+999，0~10 级预设解锁文本（测试期默认 1 级、全技能解锁）。
- **角色交互**：角色页·交互标签（左侧按钮 / 右侧打字机对话区）：夏阳 聊天·投喂·送礼，陆悠悠 聊天·送礼；聊天耗 1 行动力并实时显示成功率；送礼三级选择页、每角色每 3 天限一次、按物品隐藏喜好度触发对话与好感增减。**交互文本区严格限 5 条**（第 6 条打字结束时立即删除最早那条的 DOM，interHist 存 {el,html} 引用）。
- **元素反应**：蒸发/超载/融化/冻结/绽放/感电/激化/超导/扩散/结晶对称结算。
- **敌人寻路优化**：曼哈顿等距时选欧氏更近格，避免左右横跳；**敌人信息抗性提示**：抗性≥10 显示「X抗性较高」。
- **敌人奖励概率字段**：`reward.rate:{itemKey:count, prob:chance}` — combat.js 识别 `prob` 字段按概率掉落（prob 缺失则按 100%）。小小蛇/竹叶青/铁疙瘩等全部正确使用。
- **载具耗尽自动切换**：vehicle.js 载具使用次数耗尽时自动切回徒步，不强制打开载具页面。
- **铁疙瘩完整数值**：atk40/def20/hp500/speed10/物抗100/iron×2+rate prob:0.5/自我加固（每回合防御+5 每次攻击攻击+10）/逼近/重砸周围8格。
- **剧情区打字机增强**：storyRunNext 对非 `<p>` 开头的段（如 float div 独立块）直接 innerHTML 输出不打字机，支持常乐卡片区块。
- **事件文本排版**：6 个新事件（翻车/菜园/矿洞/修女/蘑菇/常乐）body 和 resolve 返回值全部改 `<p>` 分段格式，内容紧密同段、关系松跨段。
- **常乐·猜牌视觉**：玩家选完牌型后才抽牌（picks 移到 changleResolve 生成）；卡片用 float:right + 96px 宽独立区块贴剧情区右侧，不占正文高度、不触发滚动；3 张矩形框 emoji 扑克 + 小/大/王标签 + 统计行。
