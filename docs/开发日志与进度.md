## 一、当前实现状态（✅ 已上线）

### 核心循环
- 每天随机地图 → 探索收集/遇敌 → 回合战斗 → 睡觉进下一天（自动存档）。
- 健康归零 → 全局失败 Game Over（可读档/回主界面）。

### 探索
- 点击格子+「前往」或 WASD 移动；行动力 AP（初始/上限 5，帐篷可 +1）。
- 空地搜索（档位 50%，至多 6 资源）；奖励格新表；事件（商人/温泉/虚惊/迷路旅人）。
- 地图尺寸随天数递增+日波动，保底连通；地图外边框。

### 战斗
- 移动即结束我方回合；队友自动释放已选技能；敌人回合=移动+技能（意图回合初锁定，BFS 绕障逼近）。
- 状态系统、暴击（×2）、格挡/坚守、护盾(=防御)、逃跑系统、编队人数加成、元素亲和（史莱姆免疫）。
- **二批敌人全部接入（技能+天赋）**：中二病(稻草剑法/一定会回来的/帅气闪避/阿玛特拉斯)、奇怪史莱姆(吐果子)、小小蛇/竹叶青(蛇咬中毒/恐吓)、古树(反击/长脚就跑/果实奖励)、猎犬/Pro(撕咬/追逐/成长/狗友)、蓝羽·红羽镖客(飞羽/飘忽不定/致命节奏/双倍)、暴躁的熊(掌掴/冬眠/狂躁/稀有生物)、遗弃机关(践踏/飞弹/大清扫/巡逻)。雷史莱姆·导电已接入。
- 多敌人依次行动（狗友/集群生效）；持续技能（冰雾/大清扫）`sustain` 连续释放后入冷却；【燃烧】【中毒】按回合刻蚀 2% / 层数；稀有熊跨天延续剩余生命（未击败不回复）。
- 史莱姆系列技能持续有效（撞击/破土而出/吐火/水泡/冰雾）。

### 系统
