## 一、当前实现状态（✅ 已上线）

### 核心循环
- 每天随机地图 → 探索收集/遇敌 → 回合战斗 → 睡觉进下一天（自动存档）。
- 健康归零 → 全局失败 Game Over（可读档/回主界面）。

### 探索
- 点击格子+「前往」或 WASD 移动；行动力 AP（初始/上限 5，帐篷可 +1）。
- 空地搜索（档位 50%，至多 6 资源）；奖励格新表。
- **随机事件系统（js/event.js）**：8 个事件（无主之物/摔倒的老人/山野温泉/讨伐熊/穷追不舍/流浪商人/钱袋/面包），等分出率；可交互选项（选中淡绿→确认金色→2s 淡出→结果回剧情区）；打字机剧情（约30字/秒、点击跳段/清空）；事件格进入即变空地、状态存 G.activeEvent 供读档重开；事件中禁用编队/商店/睡觉/合成，背包不可用，载具无实质效果。
- **路线图**：新永久物品；持有时稀有动物格（带【稀有生物】天赋的敌人，如暴躁的熊）金标，进入消耗 1 张。
- 地图尺寸随天数递增+日波动，保底连通；地图外边框。

### 战斗
- 移动即结束我方回合；队友自动释放已选技能；敌人回合=移动+技能（意图回合初锁定，BFS 绕障逼近）。
- 状态系统、暴击（×2）、格挡/坚守、护盾(=防御)、逃跑系统、编队人数加成、元素亲和（史莱姆免疫）。
- **二批敌人全部接入（技能+天赋）**：中二病(稻草剑法/一定会回来的/帅气闪避/阿玛特拉斯)、奇怪史莱姆(吐果子)、小小蛇/竹叶青(蛇咬中毒/恐吓)、古树(反击/长脚就跑/果实奖励)、猎犬/Pro(撕咬/追逐/成长/狗友)、蓝羽·红羽镖客(飞羽/飘忽不定/致命节奏/双倍)、暴躁的熊(掌掴/冬眠/狂躁/稀有生物)、遗弃机关(践踏/飞弹/大清扫/巡逻)。雷史莱姆·导电已接入。
- 多敌人依次行动（狗友/集群生效）；持续技能（冰雾/大清扫）`sustain` 连续释放后入冷却；【燃烧】【中毒】按回合刻蚀 2% / 层数；稀有熊跨天延续剩余生命（未击败不回复）。
- 史莱姆系列技能持续有效（撞击/破土而出/吐火/水泡/冰雾）。

### 系统
- 合成、载具、商店、背包、角色页、编队、任务、设置、8 槽存档读档、ESC 退回、词条/状态悬浮、地图缩放拖拽。
- **任务系统**：接取钩子（首次遇讨伐熊事件才显示）；达标后**手动领取奖励**；奖励物品点击查看说明；备注不显示给玩家。
- **羁绊等级**：好感度 -999~+999，0~10 级预设解锁文本（测试期默认 1 级、全技能解锁）。
- **角色交互**：角色页·交互标签（左侧按钮 / 右侧打字机对话区）：夏阳 聊天·投喂·送礼，陆悠悠 聊天·送礼；聊天耗 1 行动力并实时显示成功率；送礼三级选择页、每角色每 3 天限一次、按物品隐藏喜好度触发对话与好感增减。
- **元素反应**：蒸发/超载/融化/冻结/绽放/感电/激化/超导/扩散/结晶对称结算。
- **敌人寻路优化**：曼哈顿等距时选欧氏更近格，避免左右横跳；**敌人信息抗性提示**：抗性≥10 显示「X抗性较高」。
