## 八、睡觉与存档

- 行动力不足→需睡觉进下一天；也可主动提前睡（需二次确认：AP未耗尽仍确定→确认后生效）。
- 睡/存效果：
  - 回复 `actionPoint = 当日AP上限`（不溢出上限）
  - `day += 1`（可能触发剧情）
  - 自动存档；睡觉相关天赋在此结算。
- 存档点：睡觉 / 重大剧情或分支选择前 / 手动任意时刻（战斗中=以战斗开始为锚）。死亡后可回档或回主界面。主界面可 新游戏/读档/看图鉴。读档需手动选具体存档。

```json
{""sleepEffect"" : "回复AP至上限(不溢出) + day+1 + 自动存档 + 结算睡眠天赋"}
```
