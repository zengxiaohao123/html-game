## 八、存档与睡觉

### 8.1 存档存储

- 基于浏览器 **localStorage**，键名 `yysw_saves`，共 **8 个存档位**（`MAX_SAVES`）。
- 每存档位存储整份 `G`（玩家状态）快照 + 时间戳 `_ts`；读档把该快照载入全局 `G`。
- 纯本地，无后端，不联网、不排行、不收集数据。

### 8.2 睡档 / 自动存档

- **睡觉**（主界面“睡觉”按钮或 `sleep()`）：若 AP 未耗尽会有二次确认；效果为：AP 恢复至当日上限、`day+1`、重新生成次日地图、回复 20% 最大生命，并结算永久物品（被子回血 / 陷阱收获）；随后**自动存档到存档位 2**（`saveGame(2)`）。
- **手动存档**：设置面板中选择存档位保存（任意时刻）。
- 死亡（健康归零）后：可“读取存档”或“返回主界面”；`health==0` 全局失败 → 游戏结束弹窗。

### 8.3 战斗存读档（以战斗开始为锚点）

- 战斗中设置面板文案为「存档（回本次战斗开始时）」。
- 战斗开始时 `initCombatState` 记录 `startSnapshot`（主角生命、载具、当前选中的载具、敌人 key/位置/生命）。
- 战斗中存档：`saveGame` 会把**生命与载具回退到战斗开始瞬间**，并写入 `snap.combat` 标记。
- 读回战斗存档 → `loadIntoWorld` 检测到 `G.combat` 即调用 `reenterCombat` **直接进入战斗**（剧本区立即变为战斗技能区），敌我状态均回到战斗开始。
- 战斗中：编队 / 睡觉 / 商店 / 合成禁用；背包仍可打开查看。
