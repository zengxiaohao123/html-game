## 2026-10-11 · M1 美术风格校正 + 探索地块图片化

**重要：美术风格基线确认（项目所有者拍板）**
- 作品采用本地素材库《魔王不过如此 / DemonLordJustABlock_Assets》的风格：
  **圆润 Q 版卡通手绘、粗黑描边、豆豆竖眼、高饱和糖果色、透明底 PNG**。
- 此前记忆里"2D 动漫风人物"作废，不要再往那个方向找素材。
- 地块/角色/敌人/图标/伤害一律使用真实图片素材，**不接受纯色 CSS 块或自绘 SVG 占位**；
  缺素材时优先：① 素材库内继续深挖（不要只按文件名筛选，要逐张识图）；
  ② 网上找同画风且**透明底**图片；③ 同画风 AI 生成。
- 使用时按游戏实际显示尺寸缩放，不拉伸变形。

  enemy21=眼球触手怪；enemy59=青色方块怪。
