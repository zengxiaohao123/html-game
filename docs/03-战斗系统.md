## 一、进入战斗

触发：踩到 `battle` / `emergency` / `reward`（Boss）类作战地块，或剧情强制开战。

进入流程：

```
1. 战斗快照
   const cs = {
     playerSnap: // 主角当前状态快照
     entities: { 'pro': {...}, 'xiayang': {...}, ... },
     enemies: [ enemy1, enemy2, ... ],
     summons: [],
     mapCopy:   // 地图当前状态的深拷贝（含地块附着）
     startPos:  { x, y },           // 进入点（战斗结束时还原用）
     startFacing: ...,              // 主角朝向还原
     skillGroup: [...],             // 当前编队的技能组快照
     turn: 0,                       // 回合计数
     phase: 'roundStart',           // 当前状态机相位
     nodeTriggered: {},             // 实体本回合是否已触发节点
     usedSkillThisTurn: {},         // 实体本回合是否已用技能
     usedMoveThisTurn: {},          // 主角本回合是否已移动
     actionCount: 0,                // 主角本回合的行动计数
     pendingLinks: [],              // 当前连携候选队列
     linkActive: false,             // 连携窗口打开中
     lingering: 0,                  // 残存时间剩余（毫秒，非 0 表示手动阶段已"拟结束"但还在计时）
     activeEnemyIdx: 0,             // 当前轮到行动的敌人索引
     ...
   }

2. UI 切换
   switchMode('combat')
   底部变成 #combatZone（按 06-UI·交互 §三 的两栏四行规格渲染）
   顶部 iconbar 按 06-UI·交互 §七·五 禁用规则生效（编队/背包/睡觉/商店/合成 → 禁用；存档/载具/设置 → 可用；任务/角色 → 打开但只可查看）

3. 日志："进入战斗。按 F 结束手动阶段，E 使用连携（若有）。"

4. 进入回合开始 phase = 'roundStart'
```

## 二、回合状态机（分层）

```
┌─────────────────────────────────────────────────────────────┐
│ roundStart                                                  │
│   turn += 1                                                 │
│   重置所有实体本回合标记：                                    │
│     nodeTriggered = {}                                       │
│     usedSkillThisTurn = {}                                   │
│     usedMoveThisTurn = {}                                    │
│     actionCount = 0                                          │
│                                                              │
│   主角自动朝向最近的敌人（仅视觉，不触发行动节点）            │
│   主角行动节点（只触发主角一个的节点，先扣持续 + 给防御护盾）  │
│                                                              │
│   phase = 'playerManual'                                     │
├─────────────────────────────────────────────────────────────┤
│ playerManual 玩家操控阶段                                    │
│                                                              │
│   允许的操作（见 §三）：                                      │
│     · 切角色卡（纯 UI，不触发行动）                          │
│     · 放主动技能（点 tile 或快捷键）                          │
│     · WASD 移动 / 点相邻格前往                               │
│     · 按 F 跳过                                              │
│     · Esc / 右上角逃跑按钮                                   │
│     · 随时按 E 连携（若有窗口）                               │
│                                                              │
│   结束条件（自动检测）：                                      │
│     · 残存时间归零                                           │
│     · 所有活着角色的 usedSkillThisTurn 都为 true               │
│     · 主角逃跑成功（特殊退出）                                │
│     · 主角死亡（特殊退出）                                    │
│                                                              │
│   结束后：                                                    │
│     若所有活着角色的 usedSkillThisTurn 都为 true               │
│       → 直接 phase = 'autoSkills'（不给残存时间）             │
│     否则：                                                    │
│       → 等待玩家手动触发"移动 / 跳过"                        │
│       → 触发后若仍有角色剩余次数 → 开启 lingeringTimer（1s）  │
│       → lingeringTimer 归零 → phase = 'autoSkills'            │
├─────────────────────────────────────────────────────────────┤
│ autoSkills 自动技能阶段                                     │
│                                                              │
│   按技能组顺序遍历所有 kind==='auto' 的槽：                    │
│     check preconditions（§五）                                │
│     满足 → 释放 → 冷却设为 sk.cd → usedSkillThisTurn[owner]   │
│     任一不满足 → 跳过                                        │
│                                                              │
│   每释放一个自动技能间隙 → _checkLinkWindow()                 │
│                                                              │
│   自动阶段结束 → phase = 'summons'                            │
├─────────────────────────────────────────────────────────────┤
│ summons 我方召唤物阶段                                       │
│                                                              │
│   按固定顺序（entityId 字典序）逐个执行：                       │
│     triggerNode(summon)                                      │
│     summonAI(summon)                                         │
│                                                              │
│   全部执行完 → phase = 'neutral'                              │
├─────────────────────────────────────────────────────────────┤
│ neutral 中立单位阶段                                         │
│                                                              │
│   按固定顺序逐个执行：                                        │
│     triggerNode(entity)                                      │
│     neutralAI(entity)                                        │
│                                                              │
│   全部执行完 → phase = 'enemy'                               │
├─────────────────────────────────────────────────────────────┤
│ enemy 敌方回合                                               │
│                                                              │
│   按固定顺序（x+y 升序 + entityId 字典序）逐个执行：             │
│     triggerNode(enemy)           ← 先扣冻结/束缚持续！        │
│     if 硬控 → skip 本回合                                    │
│     else enemyAI(enemy)                                      │
│                                                              │
│   全部执行完 → phase = 'roundEnd'                            │
├─────────────────────────────────────────────────────────────┤
│ roundEnd                                                     │
│                                                              │
│   tickAllCooldowns()（敌方回合末尾，所有冷却 -1）             │
│   若 cd<0 → cd=0                                             │
│                                                              │
│   phase = 'roundStart' → 进入下一回合                        │
└─────────────────────────────────────────────────────────────┘
```

## 三、玩家操控阶段的每一个操作

### 3.1 切换角色卡（纯 UI）

- 点击第一行角色卡上的某张（主角 / 夏阳 / 陆悠悠）→ `cs.currentChar = clickedCharKey`
- 切换后右侧信息选项区、技能描述区、状态芯片栏、属性面板、天赋标签**全部跟着切换**（显示这个角色的数值、buff、可用技能等）
- **不触发任何行动、不触发行动节点、不消耗次数、不转冷却**

### 3.2 放主动技能

```
tryCastActiveSkill(skillSlot):
  pre: skillSlot.kind === 'active'
  pre: !cs.hardControl[skillSlot.charKey]        // 所属角色没硬控
  pre: !cs.usedSkillThisTurn[skillSlot.charKey]   // 所属角色本回合没用过技能
  pre: cs.skillGroup[skillSlot].cd === 0          // 冷却好了
  pre: hasValidTargetForSkill(skillSlot)          // ⚠️ 规格硬门槛
  → 不满足 → UI 弹红色提示 → return
  
  if !cs.nodeTriggered[skillSlot.charKey]:
    triggerNode(skillSlot.charKey)
  
  resolveSkill(skillSlot, owner=skillSlot.charKey, source='playerManual')
  
  cs.usedSkillThisTurn[skillSlot.charKey] = true
  cs.skillGroup[skillSlot].cd = skillSlot.cd || 1
  
  cs.lingeringTimer = 1000  // 每次主动释放 → 残存时间重置 1s（不管之前是不是在手动阶段）
  // 这条是规格："一旦使用主动技能，立即重置残存时间"
```

### 3.3 WASD 移动 / 点相邻格

```
tryMovePlayer(dir):
  pre: !cs.hardControl['pro']
  pre: !isBlocked(...)
  
  // 规格：移动算一次行动（面向障碍格只转向也算）
  cs.actionCount += 1
  cs.usedMoveThisTurn['pro'] = true
  
  const target = adjacentCell(hero.pos, dir)
  if !canEnter(target):
    // 面向障碍格 → 只转向 + 不位移 + 仍然算移动消耗
    hero.facing = dir
    return
  
  hero.facing = dir
  hero.pos = target
  // 队友位置/朝向跟主角同步
  
  // 移动后：
  cs.summonPhaseTriggered = true  // 标记本次手动阶段玩家做了什么
  
  // 规格：移动触发残存时间判断
  if anyAliveCharNotUsedSkill():
    startLingeringTimer(1000)
  else:
    // 所有角色都没技能次数了 → 直接进自动阶段
    phase = 'autoSkills'
```

### 3.4 按 F 跳过

```
trySkip():
  pre: !cs.hardControl['pro']
  
  cs.actionCount += 1
  cs.usedMoveThisTurn['pro'] = true  // 规格：跳过也视为一次移动
  
  // 后续逻辑完全同移动的"残存时间判断"分支
  // 然后手动阶段自动结束
  if anyAliveCharNotUsedSkill():
    startLingeringTimer(1000)
  else:
    phase = 'autoSkills'
```

### 3.5 逃跑

```
tryFlee():
  pre: 主角正处于玩家操控阶段
  pre: cs.actionCount === 0
  pre: !cs.hardControl['pro']
  
  // 规格：先触发主角行动节点
  if !cs.nodeTriggered['pro']:
    triggerNode('pro')
  
  const rate = calcEscapeRate()
  
  if Math.random() * 100 < rate:
    // 逃跑成功 → 直接退出战斗
    endCombat({ outcome: 'flee', restorePos: true })
  else:
    // 逃跑失败：
    // 1. 主角视为"使用跳过"（手动阶段直接结束）
    cs.actionCount += 1
    cs.usedSkillThisTurn['pro'] = true   // ❗️ 主角失去技能次数
    // 2. 队友不受影响（队友的 usedSkillThisTurn 保持原值）
    // 3. 手动阶段立即结束 → 进自动技能阶段
    if anyAliveCharNotUsedSkill():
      startLingeringTimer(1000)          // 残存时间留给队友
    else:
      phase = 'autoSkills'
```

#### 逃跑概率公式

```
enemy = 主角速度 - max(敌人速度 * 该敌人剩余生命值百分比)（取所有敌人里最大的那一个）
rate = clamp(enemy / 100, 0, 100)（四舍五入保留 1 位小数）
```

多个敌人时，只挑那个"敌人速度 × 剩余 HP%"最大的敌人算。速度最低 0、最高 999，天然限制率的上下限。

### 3.6 连携（E 键）

```
// 玩家按 E：
onPressE():
  if !cs.linkActive: return
  
  const slot = cs.pendingLinks.shift()  // 取队首
  
  // 立即关闭窗口
  cs.linkActive = false
  
  // 规格：连携不触发行动节点
  resolveLinkSkill(slot)
  
  // 连携释放后，继续检查下一个是否还有候选
  // （如果当前阶段还能被连携插入的话）
  
// 连携候选队列的构建：
_checkLinkWindow():
  // 每一个阶段之间的间隙都调用这个函数
  
  // 过滤：冷却=0、所属角色没硬控、专属前置满足、窗口打开前必须有合法目标
  const available = skillGroup.filter(sk => {
    sk.kind === 'link'
    sk.cd === 0
    !cs.hardControl[sk.charKey]
    meetsLinkPrecondition(sk)
    hasValidTargetForSkill(sk)
  })
  
  // 规格：按技能组顺序排队
  if available.length > 0 && !cs.linkActive:
    cs.pendingLinks = available
    cs.linkActive = true
    startLinkCountdown(2000)  // 给第一个连携 2 秒窗口
    
  // 倒计时走完 → 自动 shift 到下一个 → 重置 2 秒窗口
  // 如果已经是最后一个也超时 → linkActive = false → 回到原本的正常行动
```

#### 连携可插入的时机（无动画版本）

| 阶段 | 能否插连携 | 规格场景 |
|---|---|---|
| 主动技能 resolveSkill 内部 | ❌ 主动技能是同步原子操作 | 几乎不会触发 |
| 主动技能刚放完、玩家还在手动阶段 | ✅ 玩家此时还没按移动/跳过，连携可以插在残存时间之前 | 主流场景之一 |
| 自动技能阶段、每个自动技能放完之后 | ✅ **最主要的连携场景** | 自动技能是逐个同步执行，每个间隙都给连携窗口 |
| 我方召唤物 AI 执行完、中立单位开始前 | ✅ | 间隙触发 |
| 中立单位执行完、敌方回合开始前 | ✅ | 间隙触发 |
| 敌方 AI 执行完、敌方回合末尾 tick 前 | ✅ | 间隙触发 |

**未来动画化后**：每个 `await` 之后都是可打断间隙，连携可以在动画播放中直接插入（调用栈恢复机制挂起原动作 → 连携执行 → 恢复原动作断点）。

## 四、行动节点

```
triggerNode(entityKey):
  const ent = cs.entities[entityKey]
  if !ent || ent.dead: return
  if cs.nodeTriggered[entityKey]: return  // 本回合已触发过
  
  // 防御护盾先给（回合开始时给的是主角节点触发 + 回合开始时给的"全局防御"——统一在这里做）
  // 规格："该单位的每个回合开始时获得等同于 100% 局内防御的护盾"
  ent.shield += ent.displayDef  // displayDef = 局内防御
  
  // ⚠️ 先扣承受者自己身上的 buff/debuff 持续时间
  for buff in ent.buffs:
    buff.duration -= 1
    if buff.duration <= 0: ent.buffs.remove(buff)
  
  for debuff in ent.debuffs:
    debuff.duration -= 1
    if debuff.duration <= 0: ent.debuffs.remove(debuff)
  
  // 结界/境界挂载在 triggerEntity 身上的，也在这个 triggerEntity 的节点上扣
  // （燃烧/感电/超导有独立计时器，不走这里）
  for zone in cs.zones.filter(z => z.triggerEntityId === entityKey):
    zone.duration -= 1
    if zone.duration <= 0: cs.zones.remove(zone)
  
  cs.nodeTriggered[entityKey] = true
```

## 五、自动技能阶段（`_phaseAutoSkills`）

```
phase = 'autoSkills':
  for slot in cs.skillGroup.sort(by slot.slot).filter(s => s.kind === 'auto'):
    // 四个前置条件：
    if slot.cd !== 0: continue
    if !hasValidTargetForSkill(slot): continue     // ❗️ 没目标直接跳过
    if cs.hardControl[slot.charKey]: continue
    if cs.usedSkillThisTurn[slot.charKey]: continue
    
    // 释放
    if !cs.nodeTriggered[slot.charKey]:
      triggerNode(slot.charKey)
    
    resolveSkill(slot, owner=slot.charKey, source='auto')
    cs.usedSkillThisTurn[slot.charKey] = true
    slot.cd = slot.cdDecl || 1
    
    _checkLinkWindow()  // 每个自动技能后给连携窗口间隙
  
  phase = 'summons'
```

**细节**：自动技能**必须先触发 owner 的行动节点再释放**（规格："自动技能使用前重新检查冷却、目标、硬控制、技能使用次数；执行中可被连携打断，也可被元素反应中断"）。

## 六、敌方回合（`_phaseEnemyTurn`）

```
phase = 'enemy':
  const order = cs.enemies.filter(e => !e.dead)
                .sort((a, b) => (a.x+a.y) - (b.x+b.y) || a.id.localeCompare(b.id))
  
  for (const enemy of order):
    triggerNode(enemy.key)       // ⚠️ 先扣冻结/束缚持续时间
    
    if hasHardControl(enemy):
      log(`${enemy.name} 无法行动。`)
      continue
    
    // 规格没写敌人 AI 行为的具体定义，敌人只知道：
    // 1. 有行动节点
    // 2. 按固定顺序执行
    // 3. 可以被连携打断
    // 4. 行动中若产生元素附着 → 触发元素反应
    
    enemyAI(enemy)
  
  tickAllCooldowns()             // 敌方回合末尾统一扣冷却
  // tickAllZoneTimers()（如果有）
  
  phase = 'roundStart'
```

## 七、元素反应处理栈

```
resolveElementReaction(triggerCell, oldElement, newElement, triggerEntity):
  reactionStack = []
  
  const rxn = REACTION_TABLE[oldElement + '+' + newElement]
  if rxn === undefined:
    // 无法反应 → 后者取代前者
    triggerCell.attach = newElement
    return
  
  reactionStack.push(rxn)
  
  while reactionStack.length > 0:
    const curRxn = reactionStack.pop()
    executeReaction(curRxn, triggerEntity, triggerCell)
    
    // 反应效果中产生的新附着 → push 进 reactionStack
    for each newAttachCell in curRxn.affectedCells:
      if newAttachCell.attach !== null:
        const nextRxn = REACTION_TABLE[newAttachCell.attach + '+' + curRxn.newAttachElement]
        if nextRxn !== undefined:
          reactionStack.push(nextRxn)
  
  // 扩散特殊处理：
  diffusionQueue = executeDiffusionInOrder(startedFromTop=true, clockwise=true)
  for each subEffect in diffusionQueue:
    executeSubEffect(subEffect)
    if subEffect.causedNewReaction:
      reactionStack.push(subEffect.newRxn)
  // 扩散圈全做完，再处理所有连锁反应
  
  // 硬性兜底：任何地块最多同时 1 种附着
  // （理论上经过规则 1-5 保证，这里做最后防线）
  for each cell in affectedCells:
    if cell.attach !== null && cell.attach2 !== null && cell.attach3 !== null:
      cell.attach2 = cell.attach3 = null
```

## 八、技能释放主流程

```
resolveSkill(slot, owner, source):
  const sk = getSkillFromSlot(slot)
  
  // 1. 前置校验（主动技能时 hasValidTarget 已在入口检查过了；自动/连携时也各自检查过）
  
  // 2. 若这是 owner 的第一次主动行动 → 触发 owner 的行动节点（自动在入口处理；主动在入口处理；连携不触发）
  
  // 3. 自动调向（规格：不调向；这条保留在注释里供未来可能恢复）
  // _turnOwnerEntityToFirstTarget(slot, owner)  ← 规格已删除此动作
  
  // 4. 范围计算（range = 按 rangeType + owner.facing + owner.pos 算所有格子）
  const range = computeSkillRange(slot, owner.pos, owner.facing)
  
  // 5. 索敌三条规则分类判断（由 slot.skill.desc 或 slot.skill.ruleTags 决定）
  const attachCells = filterByRule(range, rule='attachment')
  const targetEntities = filterByRule(range, rule='damage')
  
  // 6. 对 attachCells 施加元素附着（若 skill 有元素）
  if (sk.element) {
    for each cell in attachCells:
      applyAura(cell, sk.element, owner)
      // applyAura 内部：若已有附着 → 触发 resolveElementReaction → 清空 cell.attach
  }
  
  // 7. 对 targetEntities 造成元素属性伤害（skill 有元素时）
  if (sk.element) {
    for each ent in targetEntities:
      dealElementalAttrDamage(ent, sk.element, mult, owner)
      // dealElementalAttrDamage 内部：蒸发/融化 buff 生效 → 算抗性 → 冻结提前结束判定 → 最终扣血
  }
  
  // 8. 对 targetEntities 造成物理属性伤害
  if (sk.type === 'physical') {
    for each ent in targetEntities:
      dealPhysicalDamage(ent, mult, owner)
  }
  
  // 9. 对自身/队友施加 buff
  for each effect in sk.selfEffects:
    applyBuff(effect, owner)
  
  for each effect in sk.allyEffects:
    for each ally in allies:
      applyBuff(effect, ally)
  
  // 10. 检查胜负条件（本函数最末尾必须调用一次）
  checkBattleEndConditions()
```

## 九、结束战斗

```
endCombat({ outcome }):
  cs.ended = true
  
  switch outcome:
    case 'victory':
      grantCombatReward(cs.enemies)
      break
    case 'defeat':
      deductHealthByEnemyType(cs.enemies)
      if G.hero.health <= 0:
        // 全局失败
        globalGameOver()
        return
      break
    case 'flee':
      break
  
  // 还原主角位置/朝向（从快照里读）
  G.px = cs.startPos.x
  G.py = cs.startPos.y
  G.hero.facing = cs.startFacing
  
  // 主角生命值、永久加成等状态还原到快照
  // （局内 buff/debuff 清空；永久物品加成通过 _applyItemBuffs 重新结算）
  
  // 切回探索模式
  combatState = null
  switchMode('explore')
  renderMap()
  refreshHUD()
```

## 十、优先级总表（任何冲突按此从上到下裁决）

| 序号 | 优先级 | 来源 | 具体内容 |
|---|---|---|---|
| 1 | 最高 | 胜负条件 | 敌方全灭 → 胜利；主角死 → 失败；健康 0 → 全局失败 |
| 2 | 极高 | 元素反应 | 战斗中最高优先级。任何正在进行的动作立即暂停。处理到空栈后恢复原上下文 |
| 3 | 高 | 连携技能 | 可打断当前正在进行的动作。连携执行中若触发元素反应，元素反应优先插在连携剩余步骤之前 |
| 4 | 中 | 自动技能队列 | 顺序执行，每个自动技能之间给连携窗口。执行中可被连携打断、可被元素反应中断 |
| 5 | 低 | 正常行动 | 玩家操控、召唤物 AI、中立 AI、敌方 AI。可被连携打断、执行中可触发元素反应 |
