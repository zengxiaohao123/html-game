## 一、实现顺序（不是同时开工，而是按依赖分 5 批叠加）

用户说"全做"，但 **16 个系统不能同时写**——按依赖关系分 5 批，每批做完都在模拟器里跑通验证，再叠加下一批：

### 第 0 批：基础设施（必须先跑通，所有系统挂在这层）

| 模块 | 内容 |
|------|------|
| `state.lua` | 全局状态表：`gameState = { turn, day, stamina, maxStamina, gold, hp, maxHp, atk, map, fence, players, creatures, items, blessingQueue, ... }` |
| `utils.lua` | Hook 分发器（10 种时机）+ 词条注册函数 + 随机数 + 距离计算 + 回合计数器 |
| `main.lua` | OnStart → 初始化 hook → 注册玩家输入监听 → 启动主循环 |

### 第 1 批：核心循环（能走动、能睡觉、有产出）

| 模块 | 内容 |
|------|------|
| `map.lua` | 外圈 8 格 + 中心 1×1 栅栏，坐标/邻居关系/地形/内容/状态 三属性正交 |
| `input.lua` | WASD / 1~0 / P / Tab / B / C / F / L / T / J / ESC / 空格 / E |
| `turn.lua` | 推进回合（移动 +1、祈福 +1、睡觉 +N）、行动力扣减、下限 -3 强制睡、心力交瘁 debuff |
| `day.lua` | 每日开始事件：遍历所有地块触发【每一日开始时】词条 → 重置每日限次计数器 |
| `player.lua` | 余默：位置、生命（归 0 惩罚）、攻击力、行动力、金币 |

### 第 2 批：设施 + 产出 + 背包

| 模块 | 内容 |
|------|------|
| `facility.lua` | 家 / 帐篷 / 麦田 / 稻田 / 土豆田 / 郁金香 / 草莓 / 豌豆架 / 鸡舍 / 史莱姆屋 **全部 10 种设施**，按文档 v0.3 完整词条注册 |
| `bless.lua` | 祈福：2 行动力 + 1 金币，momo 随机选 1 格外圈挂祝福状态；祝福持续、可叠加次数 |
| `creature.lua` | 小鸡 / 鸡 / 史莱姆（7 种元素变体）**全部**：友善/危险/极度危险三容量、容量警告期与惩罚、投喂机制、成长值/心情值、元素免疫、粘液喷吐 |
| `inventory.lua` | 背包（8 分类 tab）+ 出货箱（12 格，次日自动出售）+ 快捷栏（10 格），移动/右键/Shift/Alt 转移 |
| `storage.lua` | 8 存档槽位 + 1 自动存档（每日开始时）+ 读档 + 存档点（事件/剧情中存档以触发点为准） |

### 第 3 批：战斗 + 技能 + 角色

| 模块 | 内容 |
|------|------|
| `combat.lua` | 物理/7 元素伤害、闪避（乘算）、小范围/大范围、伤害倍率、真实伤害、元素免疫 |
| `skill.lua` | 所有进入时/经过时/受祝福时词条（斩击、拼命、开拓、淬火、引燃、涅槃、众愿、爆炸狂欢、炽燃、焚灭、精巧射击、屏息瞄准、风止 等） |
| `buff.lua` | 粘液、燃烧、虚弱、易伤、心力交瘁、蓄力（敌人专属）**完整 6 种状态**，独立持续时间，同名取最高 |
| `unit.lua` | 角色总览：编队 1~3 + 精灵 1，编队上限每日 3 次修改，天赋不可放地块 |

### 第 4 批：UI 页面 + 建造模式

| 模块 | 内容 |
|------|------|
| `ui_topbar.lua` | 顶部状态栏：生命/攻击力/行动力/金币/三容量（超载红色闪烁） |

## 二、架构扩展要求（开发者强调"后面还有很多内容要加"）

- **新增设施**：写一个新的 Lua 表（词条描述 + hook 注册），在 `facility.lua` 里 import，不需要改核心代码
- **新增技能**：同上，写新表，`skill.lua` import
- **新增角色**：同上，`skill.lua` + `unit.lua` import
- **新增生物**：`creature.lua` import
- **新增 UI 页面**：`ui_*.lua` 独立模块，`input.lua` 里加快捷键监听，不需要改其他 UI 模块
- **新增词条 hook 类型**：在 `utils.lua` 的 hook 列表里加一行，然后所有现有模块自动支持
- **模拟器控件池**：每批叠加控件后都要测数量上限
