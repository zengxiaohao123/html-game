### 1.1 四区职责（精确分工）

| 区域 | DOM id | 位置 | 负责什么 | 什么模式下显示 |
|---|---|---|---|---|
| **行动记录区** | `#leftLog > #logBody` | 主界面**最左侧** 400px 宽 | 所有 log 文字：剧情文字、事件文字、战斗日志、天赋触发、技能释放、元素反应、商店合成…… 任何调 `window.log()` 的东西都在这里 | 四种模式**全程显示** |
| **地图主区** | `#mapWrap > #mapGrid` | 主界面**中央** | 地图所有地块渲染、拖拽、缩放、hover 预览 | 探索（可缩放拖拽）；战斗（简化，不可拖拽缩放）；剧情（锁定） |
| **信息选项区** | `#rightPanel > #promptZone` | 主界面**最右侧** 320px 宽 | **探索时**：地块 hover 详细信息 / 事件选项 / 战前预览内容<br>**战斗时**：**当前点击的地块 + 该地块上单位的详细信息**（敌人生命/最大生命/攻击/防御/元素抗性；己方单位 buff/debuff；地块元素附着；结界标记）<br>**剧情时**：**事件选项 / 主线剧情选项** | 四种模式**全程显示**（剧情时承载选项；不是剧情文字的容器） |
| **底部剧情/战斗区** | `#bottom`（内部 mode class 切换显示不同子元素） | 主界面**最底部** 250px 高 | 探索/剧情模式 → 打字机剧情文字（铺满整行）；战斗模式 → `#combatZone` 两栏布局：**左栏 `#cbLeft` 是四行严格排版的角色技能区**，**右栏 `#cbRight` 是技能描述面板**（独立列，不参与四行排版） | mode 切换时 class 从 `mode-story` 变 `mode-combat` |

## 二、信息选项区（`#promptZone`）—— 右上角，**全程存在**

### 2.1 探索时的三种内容（状态互斥）

| 状态 | 显示内容 | 触发方式 |
|---|---|---|
| **hover 地块** | 位置 (x, y)、地形类型、**最基本的地块内容**（空地 / 有作战 / 有紧急作战 / 有事件 / 有战利品 未完成 / 有 Boss 战斗 / 已被进入过 变空地 / 不可通行）、可前往性提示 | 鼠标悬停在地图某格上 |
| **默认空态** | "点击左侧地块查看信息" | 没 hover |

**规格强约束**：探索时的地块预览**绝对不显示具体敌人数量/类型、也不显示具体是什么事件**——玩家要到进入战斗 / 进入事件那一刻才知道"里面是什么"。信息选项区在探索时只告诉玩家"这格有什么类型的内容"，不剧透。

### 2.2 战斗时的内容（**只显示地块 + 单位详细信息**）

战斗时信息选项区 = **选中地块/单位的详细属性面板**：

```
地块 (3, 7) · 草地（元素：火 · 燃烧中）
├─ 单位：夏阳（我方）
│   HP: 85/120
│   攻击: 28  防御: 8  暴击率: 15%
│   元素抗性：物理 0% / 火 30% / 雷 -10% / …
│   Buff：【暴击率+10%】【攻击力+30%】
├─ 地块元素附着：火（本次战斗中 4 回合前施加）
├─ 处于【燃烧结界】范围内
│
└─ （如果地块上有敌方单位，显示敌方详细信息）
    单位：史莱姆（敌方）
    HP: 20/40
    攻击: 8  防御: 2
    元素抗性：火 -50% / 水 +30%
    Buff：【黏液·束缚（剩余 2 回合）】
```

### 2.3 信息选项区**绝对不负责**的事

- ❌ 不负责**显示技能描述**（技能描述归底部角色技能区的右侧面板）
- ❌ 不负责**显示剧情文字**（剧情文字归底部剧情区）
- ❌ 不负责**战斗中的战斗摘要（回合数、残存时间）**（规格没说；若要加请规划在底部 HUD 或角色技能区上方）
- ❌ 不负责**显示全局技能组槽位**（全局技能组在底部角色技能区 `#cbLeft` 第一行）

## 三、底部角色技能区（战斗中，mode='combat'）

### 3.0 总体布局：`#combatZone` 两栏

```
#combatZone {
  height: 250px;
  display: flex; flex-direction: row;
}

#cbLeft {
  flex: 1 1 auto;
  display: flex; flex-direction: column; gap: 4px;
  padding: 4px 8px; box-sizing: border-box;
}

#cbRight {
  flex: 1 1 33%; max-width: 33%; min-width: 240px;   /* 占战斗区约 1/3 宽度 */
  border-left: 1px solid #3a3f50;
  padding: 10px; box-sizing: border-box;
  overflow: auto;
  background: #181a2a;
}
```

> **规格硬约束**：四行严格排版只约束 `#cbLeft` 内部。`#cbRight` 是独立列，**不参与四行排版**，宽度占战斗区约 1/3。

### 3.1 `#cbLeft` 四行严格排版（高度硬锁死，总高 ≤ 242px）

```
#cbRow1 { flex: none; height: 76px; }   // 第一行：角色卡 + 技能组 + 逃跑 tile
#cbRow2 { flex: none; height: 42px; }   // 第二行：当前角色属性面板
#cbRow3 { flex: none; height: 38px; }   // 第三行：天赋标签栏（天赋=行3，状态=行4，已交换）
#cbRow4 { flex: none; height: 38px; }   // 第四行：状态芯片栏
/* 76 + 42 + 38 + 38 + 3×4(gap) = 194 + 12 = 206px ≤ 242 ✓ */
```

### 3.2 第一行：角色卡 + 技能组 + 逃跑 tile

**整行统一使用 sg-tile 组件**（尺寸 62×70、圆角 9px、2px 边框）。角色卡组和技能组之间有额外 20px gap。


左半：**角色卡**（`.charTile`）—— 独立尺寸，**不与 sg-tile 强制一致**
| 属性 | 值 |
|---|---|
| 尺寸 | **56×64**（固定，不受 sg-tile 改动影响） |
| 内容 | 角色**全名**（单行居中，"主角""夏阳""陆悠悠"都是 2-3 字，单行足够） |
| 边框颜色 | **按角色 color 字段上色**：主角 `#d9b64a`（金色兜底）、夏阳 `#e74c3c`（红）、陆悠悠 `#78c7f2`（浅蓝） |
| 选中态 | 金色光晕（`box-shadow: 0 0 0 2px #d9b64a, 0 0 12px #d9b64a60`） |

右半：**技能组 + 逃跑 tile** —— 统一使用 `.sg-tile` 组件
- 技能组永远按 **active（红）→ auto（蓝）→ link（黄）** 顺序排列（全链路强制保证：buildDefaultSkillGroup / normalizeSkillGroup / Combat.startBattle 三层均按此排序）
- `.sg-tile` 规格：
  - **尺寸 72×88**（比 charTile 稍大，因为技能名需要两行显示空间）
  - 图标本体 **保持 33×33 不变**（边框单独放大给名字留空间，图标尺寸不动）
  - 渐变底色：active 红 `#8a2a2a→#5a1a1a` / auto 蓝 `#2a4a8a→#1a2f5a` / link 黄 `#8a6a2a→#5a451a`
  - 边框颜色同渐变方向的亮色：`#cf4a4a` / `#4a7acf` / `#cfb34a`
  - 名字（`.sg-tile-label`）：**12px、最多两行、超长自动省略**（`-webkit-line-clamp:2`），`word-break:break-all` 保证长名字能拆字换行，**保证完整显示、不被图标或边框遮挡**
  - **不叠加 kind 文字徽章**——完全靠颜色表达 active/auto/link
```
[生命 85/120]  [攻击 28]  [防御 8]  [速度 30]  [暴击 15%]   ← 主角
[攻击 22]  [暴击 15%]                                      ← 队友
```

| 场景 | 显示内容 |
|---|---|
| 主角 | 生命 / 攻击 / 防御 / 速度 / 暴击（完整 5 项） |
| 队友 | **只显示攻击 + 暴击**。队友没有生命值、防御力系统、不会受伤 → 移除 HP 红条、防御、速度 |

### 3.4 第三行：天赋标签栏（`.talentTag`）

- 当前选中角色的天赋，灰色 tag（`#1a1d26` 底 + `#3a3f50` 边框）
- 字号 14px（比旧版 11px 放大）
- 点击 → 弹出悬浮面板显示天赋完整效果

### 3.5 第四行：状态芯片栏（`.stchip`）

- buff → 金色边框 + 浅金字；debuff → 红色边框 + 浅红字
- 芯片上显示名字 + 剩余回合数
- 点击 → 弹出悬浮面板显示效果定义

### 3.6 `#cbRight`（右栏）：技能描述面板

独占战斗区约 1/3 宽度（独立列，不参与四行排版）。

| 元素 | 字号 | 说明 |
|---|---|---|
| 技能名 `.sd-name` | **18px**（font-weight:800, 金色 #d9b64a） | 第一行左侧 |
| 类型徽章 `.sd-kind` | 13px | active/auto/link 小徽章（底色同 kind） |
| 冷却 `.sd-cd` | 14px | 第一行右侧，灰色 |
| 正文描述 `.sd-desc` | 14px (line-height:1.7) | 换行保留，颜色 #dfe4ef |

> **规格要求**：技能描述**首行 = 名字 + 类型徽章 + 冷却**。**不再单独显示"倍率""元素"**——这些自然信息已在正文 desc.formula 里有文字说明。
## 四、战斗时的其他可视元素

### 4.1 逃跑按钮

- **方形**（圆形已过时，规格改方形）
- **尺寸小**（和第一行的属性面板 tag 同规格，不要用大圆形按钮挤占其他行）
- **禁用规则**：`canFlee = 主角正处于玩家操控阶段 && G.hero.actionCountThisTurn === 0 && 主角未受硬控制`
  - 主角做了任何行动（哪怕只是按了一下 F、放了一次自动技能、触发了一次连携）→ 逃跑按钮立即置灰
  - 硬控制（冻结/束缚）→ 逃跑按钮置灰
  - 自动技能阶段 / 敌方回合 → 逃跑按钮置灰
- **启用时**：逃跑按钮上显示"当前逃跑概率 = N%"（实时计算，规格公式）

### 4.2 连携窗口提示

当连携窗口打开时：
- #combatZone 顶部**闪烁一行黄色提示文字**："【连携可用：燎原·连携】—— 按 E 键使用（2 秒窗口）"
- 倒计时：黄色文字旁边显示剩余秒数 "1.9s" / "1.2s" …
- 2 秒走完 → 提示消失 + 自动 shift 队列下一个连携 + 重置 2 秒窗口
- 最后一个连携也超时 → 提示彻底消失 + 回到原本流程

### 4.3 残存时间提示

规格明确**不显示残存时间**（"不显示在 UI 上但的确存在"）。所以：
- 不需要任何 UI 元素显示残存时间倒计时
- 玩家需要凭"刚移动/跳过后自己还有没有机会放技能"的感觉来把握残存窗口

### 4.4 地块元素附着渲染

战斗中地图上每个有元素附着的地块：
- **整个地块背景色**染成该元素对应的颜色（轻度染色，不盖过地块上的实体头像和地形基本形状，但让玩家一眼能看出来这个地块有附着）
- 7 种元素各一种颜色（style.css 里定义好，语义上要醒目但不刺眼：火=红、水=蓝、草=绿、雷=紫、冰=白/淡蓝、风=淡青、岩=土黄）

### 4.5 结界范围渲染

战斗中处于结界（燃烧 / 感电 / 超导）范围内的所有地块：
- **不改变地块背景色**（元素附着才染地块背景，结界有自己的渲染方式避免信息干扰）
- **地块边界线变色**（描一圈 2px 宽的结界颜色边框，不影响内部元素附着的背景色）
- 每种结界有独立颜色（燃烧=橙红、感电=电蓝、超导=紫灰）
- 允许同类结界独立存在时，多个同名结界的范围**各自独立显示**（因为是独立计时器，不能合并渲染；玩家能一眼看到"这块地叠了两层燃烧结界"）

### 4.6 境界渲染

境界是**全场唯一**的效果，视觉渲染在**底部角色技能区**：
- **角色技能区 #combatZone 的边框整体变色**（染成该境界对应的颜色）
- **角色技能区左上角**显示境界名称 + 剩余回合数的独立计时器数字（数字 16px 红色加粗，让玩家一眼能看到还有几回合）
- 不使用地块级渲染（境界范围是全场，地块级会很吵）

### 4.7 连携技能 / 双动 特效渲染

**作为重点更新的战斗玩法**，连携可用窗口、风元素"双动"剩余次数都将以**地图旁边显眼的圆形图标**显示：

- 位置：地图主区（#mapWrap）的**左侧或右侧边缘**（具体位置待定，核心要求：在地图旁显眼位置、不挡地图内容）
- 形状：圆形图标（border-radius: 50%）
- 圆形内部：连携技能图标（或"双动"字样 + 数字）
- 圆形外层：一圈**白色描边**（2px 宽）作为倒计时轨道
- **倒计时视觉**：白条随时间**逆时针减少**（从 12 点钟方向开始，绕一圈到 12 点结束）。2 秒走完一圈，走完即倒计时结束
- 多个连携排队时：并列显示多个圆形，按队列顺序从左到右（或从上到下）排列
- 双动剩余次数：圆形里显示 `×2` / `×1`，用固定白条（不走倒计时）

### 4.8 伤害 / 状态时间 / 其他浮字（规划）

**未来将以浮字实时显示在地图上**：
- 每次伤害结算 → 在目标实体头顶飞出红色 `"-8"` 浮字
- 每次触发元素反应 → 在反应地块上飞出 `"蒸发"` / `"燃烧"` / `"结晶"` 等彩色浮字
- 状态生效 → 目标头顶飞出 buff 名字的淡色浮字
- 连携触发瞬间 → 连携技能名浮字 + 圆形高亮光圈

**这些浮字将一步步接管行动记录区（#leftLog）的功能**。最后会删除行动记录区。
**但当前版本仍需保留行动记录区做文本记录和测试纠错**（规格明确）。

### 4.6 敌方意图预览

战斗开始前（进入战斗的 loading 阶段），信息选项区（#promptZone）显示：
```
即将进入战斗！
地形：草地 + 水域 + 山脉（不规则）
敌人：史莱姆×2、史莱姆法师×1、史莱姆 Boss×1（紧急作战）
```

战斗中 hover 到敌人地块时，信息选项区显示：
- 敌人名称、HP / maxHp、攻击、防御、元素抗性
- 敌人**下回合意图**（若有）：如"可能普攻"、"可能释放黏液喷射（硬控 3 回合）"
- 这条"下回合意图"目前数据层（`data.js`）里可以预留 `intentNextTurn` 字段，但**不是必须**（规格没强制）

## 五、探索时的 UI 交互

### 5.1 WASD 移动

- W/↑ 向上、A/← 向左、S/↓ 向下、D/→ 向右
- 移动自动触发 `dirToFacing(dx, dy)` 重算朝向
- 面向障碍格 → 不位移，但朝向重算 → 仍然算一次移动消耗（行动力 + 载具次数）
- 移动后自动调主角坐标 + 队友坐标/朝向 + 触发地块内容

### 5.2 鼠标点击地图

- 点地块 → 信息选项区显示地块详情 + #goBtn 按钮更新（"前往 · 消耗 N 行动力"）
- 点 #goBtn → 执行 `moveExplore(x, y, cost)`
- 点当前所在格（原地踏步）→ 走完整移动流程，触发地块内容（空地重新 searchEmpty）

### 5.3 iconbar 交互

**旧版（笼统地说"剧情/战斗态除设置外全部禁用"，且有"战斗中所有按钮禁用"一句）已废弃，以最新的 §七·五 《iconbar 禁用规则（规格精确版）》为准**。

本节仅保留交互入口说明，**禁用规则一律查 §七·五**：

- iconbar 是打开子界面的唯一按钮行；子界面包括：任务、编队、角色、背包、睡觉、商店、合成、载具、存档、设置。
- 每个按钮的**可按/禁用**状态由当前 mode（explore / story / combat）决定，精确规则见 §七·五。
- 当按钮处于禁用态：按钮 `disabled` 样式（降低透明度 + 禁用 pointer-event），hover 时给出 tooltip："当前场景下无法打开（详见规格 §七·五）"。
- 快捷键（L/P/C/B/T 等）与 iconbar 按钮**共享同一套禁用判定**：快捷键按下前必须先过 §七·五 的禁用规则，禁用态下快捷键也不响应。

### 5.4 编队界面（技能组调整的唯一入口）

编队界面模态内部**分三块并排**：

```
┌─────────────┬──────────────┬──────────────┐
│ 编队槽位      │ 技能库（角色切换） │ 技能组编辑器   │
│  [pro]       │ pro 全部技能   │ [active][auto]│
│  [xiayang]   │ (kind 分色展示) │ [auto][link]  │
│  [luyouyou]  │              │ + 合法性提示   │
└─────────────┴──────────────┴──────────────┘
```

**交互**：
1. 点击编队槽位（右侧红色 ×）→ 把该角色移出编队 → 技能组自动重排序
2. 点击技能库里的 skill tile → 右侧**技能组描述**面板显示详情
3. 再点同一个 skill tile → 切换技能组状态（没加入 → 加入；已加入 → 卸下）→ 自动重排序 + 重新编号 slot + 实时校验合法性
4. 技能组编辑器里**同类内部可拖拽**；**跨 kind 拖拽会被自动重排序拉回**
5. 实时合法性校验：
   - active 总数 ≥ 4 → 红色提示 + 禁止新增 active
   - 槽位满 → 红色提示 + 禁止加入
   - 角色不在编队 → 红色提示
   - 所有合法状态下可以拖拽 + 保存

### 5.5 角色页面（只能看、不能调技能组）

| 板块 | 内容 |
|---|---|
| 角色卡片一行 | 编队中各角色的名字 + 头像 + 当前羁绊等级 |
| 数值面板 | 当前选中角色的完整属性（主角全显、队友简化） |
| 羁绊详情 | 与其他角色的羁绊等级、近期提升事件记录 |
| 天赋列表 | 当前选中角色编入编队时自动激活的天赋技能（点击弹出完整效果描述） |
| **多形态技能形态选择**（预留） | 只有拥有多形态技能的角色（目前游戏里没有）才会显示这块；允许玩家在编队界面里切换某个技能的形态 |

**规格强制**：角色页面**不允许调整技能组**。技能组调整的唯一入口是编队界面。

## 六、剧情模式的 UI

### 6.1 剧情文字位置

剧情文字在**底部剧情区 `#bottom.mode-story #storyBox`**（250px 高，打字机式）。

### 6.2 剧情选项位置

剧情选项在**信息选项区 `#rightPanel > #promptZone`**。**绝对不是**在剧情文字区里（规格明确区分了两区）。

### 6.3 剧情控制

- **打字机自动播放**（速度：当前字符数 / 40 毫秒）
- **点击剧情文字区** → 跳到下一段；或打字机正在显示时点击 → 一次性打完整句
- **自动模式开关** → 剧情打完每段自动等 4 秒再下一段
- **跳过按钮** → 直接跳到本段落的选项页（或直接本段落结束）
- 最后一页剧情文字打完 → 自动弹出选项到信息选项区（选项会等玩家点击才继续）

## 七、快捷键总表（全游戏）

| 快捷键 | 功能 | 可用场景 |
|---|---|---|
| **WASD / 方向键** | 探索：移动；战斗：移动（方向对应前向） | 探索 / 战斗 |
| **E** | 探索：空地原地踏步 / 某些交互；**战斗：释放连携**（若有连携窗口） | 探索 / 战斗 |
| **F** | 战斗：**跳过回合**（原地不动，触发残存时间判断） | 仅战斗 |
| **1 / 2 / 3 / 4** | 战斗：**选中**当前选中角色的第 1 / 2 / 3 / 4 个主动技能（并在右侧显示该技能的详细描述） | 仅战斗 |
| **Q** | 战斗：对"当前选中的主动技能"执行**释放**操作（前提：有合法目标、冷却好了、所属角色没硬控、所属角色有技能次数） | 仅战斗 |
| **Esc** | **关闭当前模态** / **退出当前流程** / **取消选中技能**（战斗里**不包含逃跑功能**——逃跑靠右上角方形按钮） | 全局 |
| **L / P / C / B / T** | 打开编队 / 睡觉 / 角色 / 背包 / 载具（iconbar 里有） | 见 §五 · iconbar 禁用规则 |
| **Esc** + 战斗态 | 取消当前选中的技能、关闭可能打开的模态；**不会触发逃跑** | 仅取消，不逃跑 |

**主动技能释放的三选一**（当前选中某个技能后，想真正释放有三种等价方式）：
1. **再按一次对应的数字键**（比如选中后再按一次 1）
2. **按 Q**
3. **鼠标点击一次这个技能的图标**

**为什么 1/2/3/4 只做"选中"不直接释放**：因为释放要先让玩家确认右侧显示的技能描述（范围、元素、索敌规则等），避免手滑误放。

## 七·五、iconbar 禁用规则（规格精确版）

之前版本曾笼统说"剧情/战斗态禁用编队、睡觉、商店、合成"，这是不够精确的。精确规则如下：

| iconbar 按钮 | 探索态（可自由行动） | 剧情/事件态 | 战斗态 |
|---|---|---|---|
| 任务 ✅ | ✅ 打开（可查看） | ✅ 打开（**只可查看**，禁用接取/领取奖励/其他有实际影响的操作） | ✅ 打开（同上，只可查看） |
| 编队 | ✅ 打开（可编队 + 调技能组） | ❌ **禁用** | ❌ **禁用** |
| 角色 ✅ | ✅ 打开（可查看 + 交互/赠予/聊天提升好感） | ✅ 打开（**只可查看**，禁用交互/赠予/聊天/修改形态） | ✅ 打开（**只可查看**，禁用交互/赠予/聊天/修改形态） |
| 背包 | ✅ 打开（可使用消耗品、查看物品） | ❌ **禁用**（规格：事件中无法使用背包物品） | ❌ **禁用**（战斗态禁止打开） |
| 睡觉 | ✅ 可用 | ❌ **禁用** | ❌ **禁用** |
| 商店 | ✅ 可买卖 | ❌ **禁用** | ❌ **禁用** |
| 合成 | ✅ 可合成 | ❌ **禁用** | ❌ **禁用** |
| **存档** | ✅ 可用 | ✅ **可用**（规格明确） | ✅ **可用**（规格明确） |
| **载具** | ✅ 可选 | ✅ **可用**（规格明确） | ✅ **可用**（规格明确） |
| 设置 | ✅ 可用 | ✅ 可用 | ✅ 可用 |

**核心规则**：
- 剧情/事件态：**任务、角色、存档、载具、设置** 可以打开（但任务/角色只可查看，禁用有实际影响的操作）
- 战斗态：**存档、载具、设置** 可以打开；**任务、角色** 只可查看（禁用实际操作）；**编队、背包、睡觉、商店、合成** 全部禁用
- "禁用有实际影响的操作"指：不能接取任务、不能领取奖励、不能赠予物品、不能修改多形态技能形态、不能与角色交互提升好感等——只能纯查看数值

## 八、规格 vs 当前实现的已知差异清单

| 项 | 规格 | 当前代码 | 后续修复动作 |
|---|---|---|---|
| 角色卡选中高亮 | **不需要** | combat.js 里有金色光晕高亮 | 删除高亮 CSS + 逻辑 |
| 队友死亡变灰 | **队友不会死亡、不需要** | combat.js 里有透明度 + 灰度滤镜 | 删除 |

| 残存时间显示 | **不显示**（规格明确） | 若有倒计时 UI 要删掉 | 删除 |
| 角色页面能否调技能组 | **不能** | 可能有残留调整逻辑 | 彻底屏蔽角色页面的技能组编辑入口 |
