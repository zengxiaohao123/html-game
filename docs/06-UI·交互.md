## 一、全局布局（四种模式共用同一套 DOM）

```
┌─────────────────────────────────────────────────────────────────────┐
│ #hud                                                              │
│ 金币 行动力 健康 心理压力 天数 主角HP条 队友HP条                    │
├─────────────────────────────────────────────────────────────────────┤
│ #iconbar                                                          │
│ [任务][编队][角色][背包][睡觉][设置] （剧情/战斗态部分按钮禁用）      │
├─────────────────┬──────────────────────────────┬────────────────────┤
│ #leftLog         │ #mapWrap                       │ #rightPanel       │
│ 行动记录区（左）  │ 地图主区（中）                   │ 信息选项区（右）   │
│ 400px 宽         │ 自适应剩余宽度                  │ 320px 宽          │
├─────────────────┴──────────────────────────────┴────────────────────┤
│ #bottom（250px 高）                                                │
│                                                                   │
│ mode='story' → 显示 #storyBox（打字机剧情区）                      │
│ mode='combat' → 显示 #combatZone（角色技能区）                     │
│ mode='explore' → 显示 #storyBox（默认空 / 被主线剧情使用）          │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.1 四区职责（精确分工）

| 区域 | DOM id | 位置 | 负责什么 | 什么模式下显示 |
|---|---|---|---|---|
| **行动记录区** | `#leftLog > #logBody` | 主界面**最左侧** 400px 宽 | 所有 log 文字：剧情文字、事件文字、战斗日志、天赋触发、技能释放、元素反应、商店合成…… 任何调 `window.log()` 的东西都在这里 | 四种模式**全程显示** |
| **地图主区** | `#mapWrap > #mapGrid` | 主界面**中央** | 地图所有地块渲染、拖拽、缩放、hover 预览 | 探索（可缩放拖拽）；战斗（简化，不可拖拽缩放）；剧情（锁定） |
| **信息选项区** | `#rightPanel > #promptZone` | 主界面**最右侧** 320px 宽 | **探索时**：地块 hover 详细信息 / 事件选项 / 战前预览内容<br>**战斗时**：**当前点击的地块 + 该地块上单位的详细信息**（敌人生命/最大生命/攻击/防御/元素抗性；己方单位 buff/debuff；地块元素附着；结界标记）<br>**剧情时**：**事件选项 / 主线剧情选项** | 四种模式**全程显示**（剧情时承载选项；不是剧情文字的容器） |
| **底部剧情/战斗区** | `#bottom`（内部 mode class 切换显示不同子元素） | 主界面**最底部** 250px 高 | 探索/剧情模式 → 打字机剧情文字；战斗模式 → 角色技能区（4 行严格排版）；**战斗中这里的右侧是技能描述区** | mode 切换时 class 从 `mode-story` 变 `mode-combat` |

## 二、信息选项区（`#promptZone`）—— 右上角，**全程存在**

### 2.1 探索时的三种内容（状态互斥）

| 状态 | 显示内容 | 触发方式 |
|---|---|---|
| **hover 地块** | 位置 (x, y)、地形类型、地块内容（空地/有战斗/有事件 未完成/战利品 已拾取/不可通行）、可前往性提示 | 鼠标悬停在地图某格上 |
| **战前预览** | 即将进入的战斗难度（普通/紧急/Boss）、敌人数量、类型（如"史莱姆×3、史莱姆法师×1"） | 点击作战格 / 战前弹窗触发 |
| **默认空态** | "点击左侧地块查看信息" | 没 hover 也没处于战前预览 |

### 2.2 战斗时的内容（**只显示地块 + 单位详细信息**）

战斗时信息选项区 = **选中地块/单位的详细属性面板**：

```
地块 (3, 7) · 草地（元素：火 · 燃烧中）
├─ 单位：夏阳（我方）
│   HP: 85/120
│   攻击: 28  防御: 8  暴击率: 15%
│   元素抗性：物理 0% / 火 30% / 雷 -10% / …
│   Buff：【暴击率+10%】【攻击力+30%】
├─ 地块元素附着：火（本次战斗中 4 回合前施加）
├─ 处于【燃烧结界】范围内
│
└─ （如果地块上有敌方单位，显示敌方详细信息）
    单位：史莱姆（敌方）
    HP: 20/40
    攻击: 8  防御: 2
    元素抗性：火 -50% / 水 +30%
    Buff：【黏液·束缚（剩余 2 回合）】
```

### 2.3 信息选项区**绝对不负责**的事

- ❌ 不负责**显示技能描述**（技能描述归底部角色技能区的右侧面板）
- ❌ 不负责**显示剧情文字**（剧情文字归底部剧情区）
- ❌ 不负责**战斗中的战斗摘要（回合数、残存时间）**（规格没说；若要加请规划在底部 HUD 或角色技能区上方）
- ❌ 不负责**显示全局技能组槽位**（全局技能组在底部角色技能区第一行）

## 三、底部角色技能区（战斗中，mode='combat'）

### 3.1 四行严格排版（高度硬锁死）

**总高 250px**。每行高度固定（flex:none + 固定 px），行间 gap 4px，四行加起来**必须 ≤ 250px**——从设计上保证不超界，不能靠 `overflow:hidden` 裁掉。

```
#combatZone {
  height: 250px;
  display: flex; flex-direction: column; gap: 4px;
}

#row1 { flex: none; height: 50px; }  // 角色卡 + 属性面板一行
#row2 { flex: none; height: 58px; }  // 全局技能组一行
#row3 { flex: none; height: 40px; }  // 状态芯片栏 + 天赋标签（同排两栏）
#row4 { flex: none; height: 98px; }  // 右侧：技能描述面板 ← 右侧独占
/* 50 + 58 + 40 + 98 + 3×4 = 250 ✓ */
```

### 3.2 第一行：角色卡 + 属性面板（并排左对齐）

```
[pro] [夏] [陆]   攻击:15  暴击:5%  HP:100/150  防御:5  速度:30
```

| 元素 | 说明 | 规格约束 |
|---|---|---|
| 角色卡 | 每张 48×48 方块，只显示角色名字的**首字**（不带血量、不带图标） | **选中角色不需要金色高亮**。队友没有生命值系统 → **队友永远不会死亡、不需要变灰、不需要透明度** |
| 属性面板 | 当前选中角色的数值。**主角显示完整**（攻击/暴击/HP/防御/速度）；**队友只显示**攻击 + 暴击率 | 没有闪避率（规格主角完整属性里没说）；没有"逃跑速度"（统一命名为速度） |

**切换角色**：点击角色卡 → `cs.currentChar = clickedCharKey` → 后续所有信息（属性、状态芯片、天赋标签、技能描述、技能组高亮）**全部跟着切换**。**不触发任何战斗逻辑**、**不是一次行动**。

### 3.3 第二行：全局技能组

```
[主动][主动][自动][自动][连携]    ← 一行 flat 按大排序：active→auto→link
```

| 元素 | 说明 | 规格约束 |
|---|---|---|
| tile 尺寸 | 58×58 固定 | 不能大不能小，严格按设计锁死 |
| 名字 | tile 下方或 tile 内，按宽度自动 | — |
| 冷却中状态 | 灰度 50% + 半透明 + **右上角红色冷却数字徽章** | **没有金色光晕提示可放**（规格明确禁止）。冷却用"灰度 + 数字"即可 |
| kind 徽章 | 右上角小徽章（主=绿，自=蓝，连携=黄） | — |
| "可放"状态 | **不高亮**。规格说选中角色不需要高亮，同理"当前角色有剩余技能次数"也不需要额外特效 | — |
| 点击 tile | 第一次点 → 选中 tile，**第三行状态芯片栏/第四行技能描述区跟着切到这个技能**。第二次点 → **主动释放**（只有 kind=='active' 的才能放；auto/link 的 tile 点了无效） | — |

**选中角色切换时，技能组 tile 不需要根据 owner 高亮**——规格说"选中角色不需要高亮"。

### 3.4 第三行：状态芯片栏（左） + 天赋标签栏（右）

一行 split 成两栏。

**状态芯片栏（左半）**：显示**当前选中角色**身上的 buff/debuff。
- `.stchip` 样式：chip 形状 + 背景半透明 + 边框
- buff → 金色边框 + 浅金字
- debuff → 红色边框 + 浅红字
- 芯片上显示：名字 + 剩余回合数（若持续无限则不显示数字）
- 芯片可点击 → 弹出悬浮面板显示完整定义（规格：buff/debuff 需要实时更新）

**天赋标签栏（右半）**：显示**当前选中角色**编入编队后自动激活的天赋列表。
- 标签是灰色小 tag（和状态 chip 样式不同）
- 天赋永久有效、不可被驱散
- 标签可点击 → 弹出悬浮面板显示天赋完整效果描述（规格说天赋需要实时可见）

### 3.5 第四行：技能描述面板（右侧独占）

**这是战斗模式下 #bottom 右侧的独立区域**（和上面三行不是并排）。**只负责描述技能**。

#### 内容：

```
【主动】拼命
冷却 3 回合

效果：
对前方 2 格造成火元素伤害；若范围内有火附着，消耗该附着
追加造成 30% 攻击力伤害。

元素：火
范围：front2（前向直线 2 格）
索敌规则：对范围内所有可攻击敌对阵营造成伤害
（地块：范围内所有非外部地块都施加附着）
```

#### 规格硬约束：

- **技能描述区只负责描述技能**。**绝对不显示**：地块坐标、地形、地块元素附着状态、敌方单位详细属性、己方 buff/debuff —— 这些**全部是信息选项区（#rightPanel）的活**
- 当玩家**没选中任何技能**（切角色卡、点了空地等） → 技能描述区显示"点击左侧技能 tile 查看详情"提示
- 技能描述文字**照抄技能 `desc` 字段**（不做 AI 式意译），格式按技能数据里预写好的多行文本

## 四、战斗时的其他可视元素

### 4.1 逃跑按钮

- **方形**（圆形已过时，规格改方形）
- **尺寸小**（和第一行的属性面板 tag 同规格，不要用大圆形按钮挤占其他行）
- **禁用规则**：`canFlee = 主角正处于玩家操控阶段 && G.hero.actionCountThisTurn === 0 && 主角未受硬控制`
  - 主角做了任何行动（哪怕只是按了一下 F、放了一次自动技能、触发了一次连携）→ 逃跑按钮立即置灰
  - 硬控制（冻结/束缚）→ 逃跑按钮置灰
  - 自动技能阶段 / 敌方回合 → 逃跑按钮置灰
- **启用时**：逃跑按钮上显示"当前逃跑概率 = N%"（实时计算，规格公式）

### 4.2 连携窗口提示

当连携窗口打开时：
- #combatZone 顶部**闪烁一行黄色提示文字**："【连携可用：燎原·连携】—— 按 E 键使用（2 秒窗口）"
- 倒计时：黄色文字旁边显示剩余秒数 "1.9s" / "1.2s" …
- 2 秒走完 → 提示消失 + 自动 shift 队列下一个连携 + 重置 2 秒窗口
- 最后一个连携也超时 → 提示彻底消失 + 回到原本流程

### 4.3 残存时间提示

规格明确**不显示残存时间**（"不显示在 UI 上但的确存在"）。所以：
- 不需要任何 UI 元素显示残存时间倒计时
- 玩家需要凭"刚移动/跳过后自己还有没有机会放技能"的感觉来把握残存窗口

### 4.4 地块元素附着渲染

战斗中地图上每个有元素附着的地块：
- 右上角**小标签**（12×12 彩色 + 元素符号）
- 7 种元素各一种颜色（在 style.css 里定义好）

### 4.5 结界范围渲染

战斗中处于结界（燃烧 / 感电 / 超导）范围内的所有地块：
- 地块底色**半透明淡色叠加**（不盖过地形底色）
- 每种结界有独立颜色（燃烧=橙红、感电=电蓝、超导=紫灰）
- 允许同类结界独立存在时，多个同名结界的范围**各自独立显示**（因为是独立计时器，不能合并渲染）

### 4.6 敌方意图预览

战斗开始前（进入战斗的 loading 阶段），信息选项区（#promptZone）显示：
```
即将进入战斗！
地形：草地 + 水域 + 山脉（不规则）
敌人：史莱姆×2、史莱姆法师×1、史莱姆 Boss×1（紧急作战）
```

战斗中 hover 到敌人地块时，信息选项区显示：
- 敌人名称、HP / maxHp、攻击、防御、元素抗性
- 敌人**下回合意图**（若有）：如"可能普攻"、"可能释放黏液喷射（硬控 3 回合）"
- 这条"下回合意图"目前数据层（`data.js`）里可以预留 `intentNextTurn` 字段，但**不是必须**（规格没强制）

## 五、探索时的 UI 交互

### 5.1 WASD 移动

- W/↑ 向上、A/← 向左、S/↓ 向下、D/→ 向右
- 移动自动触发 `dirToFacing(dx, dy)` 重算朝向
- 面向障碍格 → 不位移，但朝向重算 → 仍然算一次移动消耗（行动力 + 载具次数）
- 移动后自动调主角坐标 + 队友坐标/朝向 + 触发地块内容

### 5.2 鼠标点击地图

- 点地块 → 信息选项区显示地块详情 + #goBtn 按钮更新（"前往 · 消耗 N 行动力"）
- 点 #goBtn → 执行 `moveExplore(x, y, cost)`
- 点当前所在格（原地踏步）→ 走完整移动流程，触发地块内容（空地重新 searchEmpty）

### 5.3 iconbar 交互

| 按钮 | 非剧情/战斗态 | 剧情态 | 战斗态 |
|---|---|---|---|
| 任务 | ✅ 打开任务面板 | ❌ 禁用 | ❌ 禁用 |
| 编队 | ✅ 打开编队界面（含技能组调整） | ❌ 禁用 | ❌ 禁用 |
| 角色 | ✅ 打开角色页面（查看数值、羁绊、天赋） | ❌ 禁用 | ❌ 禁用 |
| 背包 | ✅ 打开背包（消耗品使用、永久物品查看、杂物任务道具查看） | ❌ 禁用 | ❌ 禁用 |
| 睡觉 | ✅ 触发睡觉 | ❌ 禁用 | ❌ 禁用 |
| 商店 | ✅ 打开商店（买卖） | ❌ 禁用 | ❌ 禁用 |
| 合成 | ✅ 打开合成台 | ❌ 禁用 | ❌ 禁用 |
| 载具 | ✅ 打开载具选择 | ❌ 禁用 | ❌ 禁用 |
| 设置 | ✅ 打开设置面板 | ✅ 可用 | ✅ 可用 |

战斗中 iconbar 被 lock（所有按钮禁用）。剧情中除设置外全部禁用（规格：剧情进行中不允许角色/编队/睡觉/移动）。

### 5.4 编队界面（技能组调整的唯一入口）

编队界面模态内部**分三块并排**：

```
┌─────────────┬──────────────┬──────────────┐
│ 编队槽位      │ 技能库（角色切换） │ 技能组编辑器   │
│  [pro]       │ pro 全部技能   │ [active][auto]│
│  [xiayang]   │ (kind 分色展示) │ [auto][link]  │
│  [luyouyou]  │              │ + 合法性提示   │
└─────────────┴──────────────┴──────────────┘
```

**交互**：
1. 点击编队槽位（右侧红色 ×）→ 把该角色移出编队 → 技能组自动重排序
2. 点击技能库里的 skill tile → 右侧**技能组描述**面板显示详情
3. 再点同一个 skill tile → 切换技能组状态（没加入 → 加入；已加入 → 卸下）→ 自动重排序 + 重新编号 slot + 实时校验合法性
4. 技能组编辑器里**同类内部可拖拽**；**跨 kind 拖拽会被自动重排序拉回**
5. 实时合法性校验：
   - active 总数 ≥ 4 → 红色提示 + 禁止新增 active
   - 槽位满 → 红色提示 + 禁止加入
   - 角色不在编队 → 红色提示
   - 所有合法状态下可以拖拽 + 保存

### 5.5 角色页面（只能看、不能调技能组）

| 板块 | 内容 |
|---|---|
| 角色卡片一行 | 编队中各角色的名字 + 头像 + 当前羁绊等级 |
| 数值面板 | 当前选中角色的完整属性（主角全显、队友简化） |
| 羁绊详情 | 与其他角色的羁绊等级、近期提升事件记录 |
| 天赋列表 | 当前选中角色编入编队时自动激活的天赋技能（点击弹出完整效果描述） |
| **多形态技能形态选择**（预留） | 只有拥有多形态技能的角色（目前游戏里没有）才会显示这块；允许玩家在编队界面里切换某个技能的形态 |

**规格强制**：角色页面**不允许调整技能组**。技能组调整的唯一入口是编队界面。

## 六、剧情模式的 UI

### 6.1 剧情文字位置

剧情文字在**底部剧情区 `#bottom.mode-story #storyBox`**（250px 高，打字机式）。

### 6.2 剧情选项位置

剧情选项在**信息选项区 `#rightPanel > #promptZone`**。**绝对不是**在剧情文字区里（规格明确区分了两区）。

### 6.3 剧情控制

- **打字机自动播放**（速度：当前字符数 / 40 毫秒）
- **点击剧情文字区** → 跳到下一段；或打字机正在显示时点击 → 一次性打完整句
- **自动模式开关** → 剧情打完每段自动等 4 秒再下一段
- **跳过按钮** → 直接跳到本段落的选项页（或直接本段落结束）
- 最后一页剧情文字打完 → 自动弹出选项到信息选项区（选项会等玩家点击才继续）

## 七、快捷键总表（全游戏）

| 快捷键 | 功能 | 可用场景 |
|---|---|---|
| **WASD / 方向键** | 探索：移动；战斗：移动（方向对应前向） | 探索 / 战斗 |
| **E** | 探索：空地原地踏步 / 某些交互；**战斗：释放连携** | 探索 / 战斗 |
| **F** | 战斗：**跳过回合**（原地不动，触发残存时间判断） | 仅战斗 |
| **1 / 2 / 3 / 4** | 战斗：**选中并释放**当前选中角色的主动技能（快捷键只绑定 active） | 仅战斗 |
| **Esc** | 战斗：**尝试逃跑**；其他：关闭当前模态 / 退出当前流程 | 全局 |
| **L / P / C / B / T** | 打开编队 / 睡觉 / 角色 / 背包 / 载具（iconbar 里有） | 探索（剧情/战斗态禁用） |

**注意**：规格说主动技能释放是"两次点击"——第一次点 tile 选中（显示描述），第二次点同一个 tile 才放。**快捷键 1/2/3/4 在 combat.js 里应该直接触发第二次（释放）**，不需要模拟两次点击。

## 八、规格 vs 当前实现的已知差异清单

| 项 | 规格 | 当前代码 | 后续修复动作 |
|---|---|---|---|
| 角色卡选中高亮 | **不需要** | combat.js 里有金色光晕高亮 | 删除高亮 CSS + 逻辑 |
| 队友死亡变灰 | **队友不会死亡、不需要** | combat.js 里有透明度 + 灰度滤镜 | 删除 |
| 逃跑按钮形状 | 方形、小 | 圆形大按钮 | 改方形 + 尺寸缩小 + 挪到第一行属性面板旁边 |

| 残存时间显示 | **不显示**（规格明确） | 若有倒计时 UI 要删掉 | 删除 |
| 角色页面能否调技能组 | **不能** | 可能有残留调整逻辑 | 彻底屏蔽角色页面的技能组编辑入口 |
