## 三、数据模型（全局常量 / 对象形状）

### 3.1 主角（唯一可控单位，纯数据）

```json
{"atk":10,"maxHp":100,"hp":100,"def":0,"escapeSpeed":100,"facing":"↑","dailyActionPointCap":5,"actionPoint":5,"health":30}
```

- `atk` 攻击力=10；`def`=0（不参与常规减伤，语义=护盾+常数，见其自然公式章节）；`escapeSpeed` 逃跑速度=100。
- `health`=健康值，**全局属性、独立于战斗hp**，初始30，无上限，可无限增加；`health==0` → 全局失败，游戏立即结束。
- `facing` 朝向，初始=向上；战斗结算先更新朝向再算攻击。

### 3.2 元素枚举（着色规则见「05·界面与UI」的十/十一）

```
enum Element { fire火, water水, grass草, thunder雷, ice冰, wind风, rock岩 }
规则：fire/water/grass/thunder/ice 可作附着；wind/rock 不能作附着。
伤害类型（相互独立）：physical物理 / fire / water / grass / thunder / ice / wind? / rock?
  真实伤害(True)：不受减伤、不参与元素附着与反应、无视绝大多数乘区。
"风/岩是否可作为伤害元素" → 见「04·战斗系统」附录B 扩散/结晶（以伤害触发方出现，不作附着）。
```

## 十二、角色数据（DB，结构化）

> 每角色字段：`element`（本人属性）、`atk`、`talent[]`（天赋：`id/name/level?/desc`）、
> `skillAttack[]`（攻击技）、`skillSupport[]`（辅助技）、`skillExtra[]`。
> 数值倍率以 "atk%" 或常量表达。冷却 = 回合数。

### 主角 Protagonist（无元素，无辅助技）

```
base: atk10 / maxHp100 / def0 / escapeSpeed100
talent[6]（全自动生效，前5个含 level1，可用专属道具升级）:
  战术布置            : 效果见【重点目标】
  暴击     lv1       : atk+10, 暴击率+3%
  嗜血     lv1       : atk+20, 攻击型技能 3% 概率回复自身=本次伤害*50%
  起势     lv1       : atk+30, 使用攻击型技能后获得 4% 伤害加成
  格挡     lv1       : maxHp+50, 受攻击 3% 概率使本次伤害归零
  坚守     lv1       : 回合开始获得 30 护盾, 受攻击 6% 概率回复 12% 生命
skillAttack[5]（战斗最多带3个）:
  斩击   : 前方1格敌人, 物理, atk*100%
  万刃斩 : 周围4格全部敌人, 物理, atk*85%
  拼命   : 前方1格, 物理, atk*140%; 自身流失20%生命(可致死)
  均衡   : 前方1格, 物理, atk*70%; 自身回8%生命; 本回合自身受伤害-40%
  游击   : 2格距离内最近敌人, 物理, atk*70%
skillSupport: 无
```

## 附录A 词条库（Terms · 悬浮弹窗文案与数值）

| 词条 | 解释 |
|---|---|
| 【重点目标】 | 主角天赋设置。我方单位攻击时优先攻击该目标；场上至多1个；主角单体攻击新敌人时覆盖旧目标。 |
| 【蓄力】 | 敌人强力攻击前的准备；期间不移动不改朝向；受我方任意攻击即打断；带"难以打断"标签需更强手段。 |
| 【束缚】 | 无法移动，但可攻击。 |
| 【燃烧】 | 每回合开始流失2%生命（可致死，无来源）；持续3回合。 |
| 【闪避】 | 在敌人即将攻击前撤出攻击范围；触发时陆悠悠·蹁跹天赋为主角回30血。 |
| 【额外回合】 | 许泠朦·秋水澄心触发：仅泠朦可放技能、无移动；各类增减益不计时（时间暂停）；冷却不计少；遵每回合至多一次技能。 |
| 【偷取】 | 对方数值减少，自身数值对应增加。 |
| 【结界】 | 技能形成的区域效果；持续期内对范围内单位施加特定效果。 |
| 【禁锢】 | 无法行动。 |
| 【冰冻】 | 无法行动（动/攻/蓄力等一切主动行为，不含被动）；持续1回合。 |
| 【激化】 | ATK+15%；受雷/草伤害+25%；持续2回合。 |
| 【超导】 | 雷/冰/物理抗性各-30%；持续3回合；抗性最终结算强制限0~90%。 |
| 【离离枯荣境界】 | 叶唯安境界技能，持续4回合；叶每用技能为2格内生命最低的我方回`自身atk*210%`；期间死亡召唤物重生于周围9格只留基本属性。 |
| 【绽放结界】 | 叶唯安结界，持续3回合；召唤物ATK+35%；我方回合结束召唤物发射草元素叶片=自身atk*100%伤害。 |
| 【烈绽放结界】 | 绽放结界×组队夏阳变体，持续3回合；召唤物ATK+65%；回合结束发火元素叶片；结界消失前普通召唤物自爆，对2格内所有敌人造成自身atk*300%火伤。 |
| 【超绽放结界】 | 绽放结界×组队潘天宇变体，持续3回合；召唤物ATK+45%；回合结束召唤物流失35%生命并发射雷元素叶片；场上有任意单位倒下时召唤物ATK+8%。 |
| 【草史莱姆】 | 我方召唤物；独立面板(atk/hp)；独立移动攻击逻辑，以敌为目标；可被敌方攻击；吃到"我方单位及召唤物"加成、吃不到"我方角色/队友"加成。 |
| 【水精灵】 | 敌方召唤物；不攻击但会移动，hp极高；存在4回合；消失或被击败时对周围9格造成水元素伤害=其所受伤害的40%。 |
| 【巧遇】 | 夏阳·心想事成天赋提供的行动方式；移动至场上任意一格，每天限1次。 |
