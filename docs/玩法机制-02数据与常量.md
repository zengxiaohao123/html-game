## 三、全局常量与资源

### 3.1 存档位与元素

- **枚举与中文着色**：火 `e-fire` / 水 `e-water` / 草 `e-grass` / 雷 `e-thunder` / 冰 `e-ice` / 风 `e-wind` / 岩 `e-rock`。
- **可附着元素** `AURA_ELEMS`：火 / 水 / 草 / 雷 / 冰（风、岩不可附着）。
- 伤类型：`physical`物理 / `real`(或 `true`)真实 / 各元素。真实伤害不参与减伤、附着与反应。

### 3.2 区域与资源

- `RES_ZH`：木材 / 果子 / 亚麻 / 生肉 / 金币 / 空瓶子 / 铁块。
- **自然资源** `NATURAL_RESOURCES`：木材 / 亚麻 / 果子 / 生肉（可被“陷阱”睡觉随机、城市外探索掉落）。
- **铁块**：特殊资源，非自然/城市资源，无法常规探索获得，仅特殊来源 / 商店购买。
- 🧩 **区域切换（wild/city）**：`G.region` 当前恒为 `wild`，探索池据此使用自然资源；“城市”切换均为**规划中**（代码 `G.region` 未真正切换）。

### 3.6 商店（`SHOP_ITEMS`，快捷键入口“商店”）

- 资源（均可购、可售，出售价=买入价×50%）：木材 2 / 亚麻 3 / 果子 2 / 生肉 4 / 空瓶子 5 / 铁块 6。
- 仅购不可售：匕首（基 32）、皮衣（基 20）。`priceGrow=4`：每获得 1 个，商店售价 +4（动态价）。
- 篝火 / 陷阱 / 木棒 / 布衣 / 铁剑 / 盔甲 / 被子不入商店。

## 十三、状态 / 状态库（`js/combat.js` 的 `ST`）

| 状态 | 类型 | 效果 |
|---|---|---|
| burn 燃烧 | debuff ·3回合 | 每回合开始流失 2% 生命（可致死，无来源） |
| bind 束缚 | debuff | 无法移动，但可攻击 |
| atkUp 攻击提升 | buff ·2回合 | 攻击力 +25% |
| shield 护盾 | buff | 抵消等量伤害（不抵流失类），每回合刷新 |
| alert 重点目标 | debuff | 我方攻击优先打该目标，场上至多1个 |
| dr 伤害减免 | buff ·1回合 | 本回合受伤害 -40% |
| crit 屏息 | buff ·2回合 | 下一次攻击暴击率 +100% |
| cage 禁锢 | debuff ·2回合 | 无法行动（主角被禁可移动但无实际效果，仅用于结束回合） |
| poison 中毒 | debuff | 回合开始流失层数点生命，可叠加 |
| sleep 睡眠 | debuff | 无法移动/攻击；受伤害致生命降低会提前醒来 |

> 🧩 **以下词条仅有 `data.js` 中的解释文案（TERMS），代码尚未有技能赋予对应状态/结算**：`aggro 激化`、`superconduct 超导`、`frozen 冰冻`、`zone 结界`、`extraTurn 额外回合`、`steal 偷取`、`dodge 闪避`。状态悬浮/词条悬浮已能展示，但**释放逻辑未接入**。

### 15.1 已实现敌人效果说明（`js/combat.js`）

- **通用移动**：所有带 `move` 技能敌人都可 BFS 绕障逼近（✅）。
- **通用近战「撞击」**：仅 `slimebang` 有专属执行（前方1格造成伤害）。
- **专属技能已执行**：`slimeburst 破土而出`、`firespit 吐火`、`waterbubble 水泡`、`icemist 冰雾`。
- **已接入天赋**：`newbie`(史莱姆前12天 maxHp-60)、`rockshield`(岩盾)、`swarm`(集群)、`windswirl`(风旋)、`元素亲和`(免疫对应元素+常附着，`AFFIN_IMMUNE`)、`sleep 唤醒`。
- **当前敌人伤害缺口**：`castEnemySkill` 只针对史莱姆系列执行；其余敌人（中二病/蛇/熊/机关等）的技能落入通用分支，**只播报文案、不造成实际伤害** → 这些敌人目前实际处于“无法正常进攻”的状态，属未完成项。
