# 异世界流浪日记 · 玩法机制 · 战斗系统

> 本文是《异世界流浪日记》玩法机制文档系列的第四篇，对应游戏代码模块**「战斗系统」（js/combat.js）**。
> 内容来源《玩法机制介绍-总篇》的：六、战斗系统；七、逃跑机制；九、伤害公式；十三、召唤物与额外回合；附录B 元素反应。

## 六、战斗系统

### 6.1 战斗的地图语义

- 与探索共用同一张格子地图；进战斗后切换交互模式。
- 战斗中探索态的其他敌人/事件被隐藏（不移动不变），保证战后探索不变。
- **战斗结束强制传送回进入战斗那一格**（该格始终无实体，可安全落点）。战斗中产生的破坏战后立即还原；少数非破坏性改变经特殊说明方可保留。
- 战斗移动**不消耗探索 AP**。

### 6.2 回合结构与次序

```
我方行动(每个角色每回合至多1次技能；移动视为我方回合结束，无需"结束回合"键)
  → 敌人行动 → 下一我方回合。我方回合+敌人回合=1个回合。
每个角色可：移动前主动选技能(按Q释放,按当前朝向结算) 或 移动后系统自动释放已选技能(按新朝向结算)。
```

- 角色切换：鼠标点头像 或 `F1/F2/F3`；技能选择：鼠标 或 数字`1/2/3`；按`Q`释放。选择状态一直保留，初始默认第1个技能。
- 自动释放顺序=队伍一二三号位（已放过的跳过）；手动提前释放则无影响。
- 自动释放失败（条件不满足）→ 该角色本回合计移动不攻击；移动前手动释放失败 → 视作未使用技能并给文字提醒。
- 工具栏：默认「徒步跋涉」=不用工具；按`T`打开工具选择页。工具可携无数量上限，**每次移动只能用1个**；切换工具不耗AP不耗战斗回合。工具使用耗次数，耗尽即消失（不可补次，只能购新；同名工具可多份独立计数）。探索用工具移动耗1AP（少数工具特殊：本次不耗AP）。默认移动仅上下左右，目标格无实体无阻挡；部分工具允许斜向/跳格/越障但不许停在障碍/实体格，只停合法空格。使用方式：只能点击格子+前往按钮。

### 6.3 朝向

- 主角初始朝上。移动后按"两格连线方向"更新朝向；45°角按 上>右>下>左 优先级定。WASD移动新朝向=移动方向；点击格+前往移动，朝向=连线方向。
- 敌人也有朝向：敌人在本回合开始由 AI 预判是否移动及攻击朝向；**使用的技能不由 AI 选**，由敌人逻辑+随机概率控制。即使主角移动致攻击落空，敌人仍按既定方案执行。
- 【蓄力】：少数敌人技能需蓄力数回合，确定后不可改朝向，蓄力期间不移动不改朝向；期间受我方任意攻击即被打断（少数带"难以打断"标签需更强手段）；被打断敌人直接跳过本回合，少数并被附加负面效果（届时特殊说明）。

### 6.4 敌人 AI（固定逻辑）

- 每回合开始仅基于玩家/可攻击单位**当前位置**行动，计算移动与朝向；**完全不考虑我方本回合将发生的移动**，算完照执行（即使落空）。
- 敌人移动受限：不可进实体格/阻挡格。攻击永远只打主角（队友=同单位，地图只显示主角）。
- 大部分敌人在非战斗时不移动；有移动逻辑的敌人各不同。
- 敌人速度无通用公式，作者逐敌设计。

### 6.5 战斗胜负与失败后果

- 胜利：击败本场所有敌人 或 敌人逃跑；（少数特殊战斗有特殊胜利条件）。
- 失败：主角 hp==0。失败后 hp=1，**health 减少（作者为每敌专属固定值）**。health==0 → 全局失败游戏结束。
- 逃跑：特定敌人的特殊行为，每敌概率公式不同；敌方逃跑 → 战斗立即胜利、无需追击、奖励可能不同。

### 6.6 我方面板与增益生命周期

- 战斗内所有加成（攻击加成/护盾等）**战斗结束立即清空**；特殊加成单独说明。
- 主角属性：`atk10 / maxHp100 / def0 / escapeSpeed100`（见「02·数据与常量」3.1）。
- 护盾：抵消等量伤害，**但无法抵消失血类(如 burn 流失)效果**。每新我方回合开始清除上一回合全部护盾（=每回合刷新）；少数手段可保留（特殊说明）。**不设计敌人给我方上护盾的机制**。
- 防御语义：`def = 该单位护盾 + 某常数`，不参与常规减伤公式。
- 队友无 hp 概念：敌人只打主角 hp，队友不吃伤害；队友有 atk，技能伤害与其 atk 相关；给"某人加攻击"时明确名字，否则语境判断。

### 6.7 队伍

- 上限=含主角共 3 名；主角基本强制在队。
- 队友可自由换入/换出，离队羁绊等级不消失；羁绊驱动剧情（与是否在队无关）；离队不以NPC出现（出现则=剧情需要）。
- 顺序=一号/二号/三号，影响自动释放次序。
- 天赋：被动，只要在队即生效；战斗类天赋战斗结束清效果并清零计数；全局类全局生效。

### 6.8 技能规则

- 技能三类：攻击 / 辅助 / 天赋。攻击+辅助每角色共最多带 **3 个**（不是各3）。每回合每角色最多用 1 次技能（攻/辅二选一）。
- 主角技能升级：重复获取某类道具提升某技能等级，每类道具只升一个技能，无上限。
- 队友技能等级 = 其羁绊等级；部分技能需满足特定羁绊等级才解锁；羁绊 1~10 级，每队友独立、技能/解锁等级各不相同且唯一。

## 七、逃跑机制

- 每回合玩家可选逃跑，前提：本回合**尚未移动**且**未使用主角技能**（队友会照常自动释放已选技能）。
- 成功率：概率性，与 `逃跑速度 vs 敌人速度` 相对值相关；两值皆隐藏，但游戏在逃跑选项下**显示计算得的概率**。非战斗时可在角色处查看逃跑速度。
- 失败：本回合主角不能移动不能技能。成功：战斗立即结束，无奖励无惩罚，但**永久 `escapeSpeed+1`**。每回合皆可尝试，无次数限制。

## 九、伤害公式（伪代码，结算顺序严格）

### 9.1 我方 → 敌方

```
baseATK = atk * (1 + atkPctBonus) + atkFlatBonus        # 攻击力基础值
atk_value = baseATK
if 伤害类型匹配: atk_value *= (1 + ponName)             # 元素伤害加成(须类型匹配)
atk_value *= (1 - target元素或物理抗性)                  # 与伤害类型对应
atk_value *= (1 - target减伤)                          # 对真实伤害外全部生效
atk_value *= skill倍率
atk_value *= 各种乘区(易伤/增伤等)                       # 同名效果同乘区叠加；不同名=不同乘区
final = atk_value * (1 + 最终伤害加成)                   # "最终伤害加成"=专有名词特殊乘区
```
- 元素/物理抗性只对对应伤害类型生效。减伤对真实伤害外全部生效。防御不参与上述公式。

### 9.2 敌方 → 我方

```
dmg = 自身atk*(1+atkPctBonus)+atkFlat   # 敌方基础攻击值
dmg *= 伤害倍率
dmg *= (1 - 受攻击我方减伤)              # 真实伤害除外
dmg *= 敌方自身增伤/减伤效果
dmg += 特殊攻击方式伤害                   # 特殊公式独立，如：反弹=本次所受伤害*60%真伤，仍*（1-受攻击我方减伤）
```

### 9.3 护盾 & 特别结算

- 护盾==抵消等量伤害；不抵流失(如 burn)。
- 每回合开始清盾（刷新）。

## 十三、召唤物 & 额外回合（机制章节）

- 【草史莱姆】我方召唤物：独立面板(atk/hp)、独立移动攻击逻辑以敌为目标、可被敌攻；敌人范围内多可攻击对象且超出攻击数量时随机攻击。吃"我方单位及召唤物"加成，不吃"我方角色/队友"加成。"发射叶片"是【于此绽放】结界附加效果，非召唤物自带行为。
- 【水精灵】敌方召唤物：不攻击、会移动、hp极高；4回合后消失或被击败→周围9格水伤=所受伤害40%（见「02·数据与常量」附录A词条）。
- 【额外回合】（泠朦·秋水澄心）：累计护盾≥720触发1个【额外回合】。额外回合内仅泠朦可放技能、无移动，基于当前位置与当前朝向释放；增减益不计时长（时间暂停）；冷却不计少；仍遵每回合至多1次技能。因时间暂停，冷却在额外回合不减少。

## 附录B 元素附着与反应（反应表 / 触发，精确）

### B.1 附着（Aura）

- 物理/真实伤害不参与附着与反应。
- 两类操作：①造成某元素伤害=先结算这次伤害，再施加该元素附着；②施加某元素附着=无伤害，直接挂附着。
- fire/water/grass/thunder/ice 可附着，wind/rock 不可。
- 一单位同时只存在一种附着；后来者直接顶替前者的附着。
- 附着持续到战斗结束（类似增益/减益）；本身无效果，仅作为反应载体。

### B.2 反应触发原则

- 触发条件：目标身上有元素附着，且受到与附着元素形成反应的那次元素伤害 → 触发对应反应。
- 反应后该目标附着立即消失（优先级极高，不影响后续附着）。若同回合又受新元素伤害，可立即附上新元素二次触发。
- **每回合反应次数无上限**。**元素反应本身造成的伤害禁止再施加元素附着**。
- 多段元素伤害**逐段结算**：结算此段→如发生附着/反应立刻处理（加成、旧附着消失、新附着添加）→处理完再算下一段（防多段计算爆炸）。

### B.3 反应表

| 触发(附着+受击) | 反应 | 效果 |
|---|---|---|
| 火 + 水伤 | 蒸发 Vaporize | 本次水元素伤害最终伤害+50% |
| 火 + 草伤 | 燃烧 Burning | 目标获【燃烧】3回合：每回合开始流失2%生命（可致死，无来源） |
| 火 + 雷伤 | 超载 Overload | 对目标及周围4格与该单位同阵营单位造成`施加者atk*20%`火伤（此伤不再二次附着） |
| 火 + 冰伤 | 融化 Melt | 本次冰元素伤害最终伤害+100% |
| 水 + 冰伤 | 冻结 Freeze | 目标获【冰冻】1回合：无法行动（主动行为），被动除外 |
| 水 + 草伤 | 绽放 Bloom | 周围9格随机1空格生成我方【草史莱姆】 |
| 水 + 雷伤 | 感电 Electro-Charged | 对目标造成`施加者atk*10%`雷伤；再对周围9格随机1名同阵营目标同样伤害，并以其为基准递归，但不能选中本次感电已伤害过的单位；最多5名，范围内无符合条件的则停止；此伤不再二次附着 |
| 草 + 雷伤 | 激化 Aggravate | 目标获【激化】2回合：ATK+15%，受雷/草伤害+25% |
| 雷 + 冰伤 | 超导 Superconduct | 目标获【超导】3回合：雷/冰/物理抗性各-30%；抗性最终限0~90% |
| {火/水/雷/冰}附着 + 风伤 | 扩散 Swirl（特殊） | 对目标及2格内同阵营单位造成`施加者atk*30%`对应元素伤害（火附着→扩散火伤） |
| {火/水/雷/冰}附着 + 岩伤 | 结晶 Crystallize（特殊） | 施加者立即获得=自身def*150%的护盾（4种触发效果相同） |

- 顺序：两元素先后顺序不影响反应结果，唯两例外：
  1) 蒸发/融化明确要求"后者伤害获得最终加成"，换序看后者伤害但倍率不变；
  2) 扩散/结晶因 wind/rock 不可作附着，只能作后者（伤害触发方），顺序固定。
- 未列出的元素组合=无法反应。同元素(如火+火)=无法反应，附着保持；不同元素无法反应(如草+冰)=附着变为最后施加那种（新附着顶替旧附着）。
