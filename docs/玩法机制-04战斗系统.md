## 六、战斗系统（js/combat.js）

### 6.0 一次战斗的完整流程（伪代码）

```
startCombat(进入战斗格) → initCombatState（生成敌人、记录 startSnapshot、enterCombatMode；敌人于敌方回合开始即时决策）

每回合：
  1) 玩家操作（当前角色 currentChar）：
     - 用 1/2/3 选技能（再按一次 或 按 Q）→ 移动前主动释放；或直接 WASD / 点格+「前往」移动。
     - 移动即结束我方回合（playerMoved=true）。
     - 移动后：autoCastAll 让全队依次自动释放各自已选技能（无目标则跳过）。
  2) endPlayerPhase → 敌方回合（每个存活敌人依次在己方回合开始时用规划器决定并执行移动/朝向/技能）→ turn++
  3) 结算 burn/poison 流失 → 我方/敌方状态 tick（倒计时、熊唤醒检测）→ 竹叶青·恐吓+ → 解析 延迟水泡 → 护盾刷新（=防御力）→ 玩家可再次行动
重复直到 敌人全灭(胜利) 或 主角 hp<=0(失败)。
```

### 6.1 地图与进入/结束

- 与探索共用同一张格子地图；进入战斗后切交互模式（`mode=combat`），探索态其它内容不参与战斗。
- **战斗结束强制传送回进入战斗那一格**（`entryCell`），该格战斗内容清空变空地。
- 战斗移动**不消耗探索 AP**；每次真实移动仍消耗已选载具（见 05）。

### 6.2 我方操作

- **角色切换**：鼠标点角色卡 或 `F1/F2/F3`（当前角色 `currentChar`）。三名角色均由玩家操控、各自独立算每回合 1 次技能。
- **技能选择**：`1/2/3` 选技能、`4` 选中「逃走」；再次按下所选技能（或按 `Q`、或双击技能）主动释放；技能种类分 攻击/辅助。
- **释放时机**：移动前主动释放（不视为已移动）或 移动后系统自动全队释放（未用者自动放、已用者跳过）。
- **移动**：WASD 或 点击相邻格+「前往」，二选一即结束我方回合；朝障碍/地图外只转向并计入已移动。
- **受限移动**：被【禁锢】时移动无实际效果（仅结束回合）；被【束缚】时不仅无效且不改变朝向。

### 6.3 敌人 AI（敌方回合即时决策 · 行动规划器）

- **敌方回合开始时**，敌人按当前场上局势**即时决定**本回合的行动（移动/朝向/技能），逐个敌人依次决策执行；不再回合前预锁意图。
- **三种移动方式**：1 不移动；2 不移动但改朝向；3 移动，且朝向按“移动起点→终点向量”决定（斜向45°时在相邻两正方向中选能命中目标者；否则取主导轴正方向；一回合多步则每步更新朝向）。
- **命中优先**：不移动即能命中→直接攻击；否则移动后命中→移动并攻击（选尽量不贴脸的远距命中点）；再不行→单纯移动，不攻击。
- 特殊分支优先：持续技能（冰雾/大清扫）`sustain` 续用；机关满血走「巡逻」随机方向；被【束缚】的敌人不可移动/转向、仅可攻击；机关飞弹需先**蓄力**1回合再发射。
- **攻击目标**：只攻击主角（队友视为同单位，地图只显示主角）。
- **多敌人**：敌方阶段所有存活敌人依次行动（狗友/集群生效）。
- **意图显示**：因决策在回合开始提交，信息区改为**模糊意图**（攻击 / 移动 / 逃跑 / 强化自身 / 施加削弱，可并用「/」），由敌人技能组判断。

### 6.4 伤害与抗性（当前简化公式）

```
双方基础攻击：
  主角: charAtk('pro') = G.hero.atk + 各含 atk 的天赋加成 + 攻击提升(atkUp +25%)
  队友: c.atk + 各含 atk 的天赋加成
  敌人: 生成时 atk × 编队加成

我方 → 敌人:
  dmg = round( 攻击力 × (1 − 敌对应抗性/100) × 技能倍率 × (1 + 起势加成 mom/100) )，最小1
  暴击率 =（天赋暴击 + 屏息/比翼 + ）限幅 0~100%；命中暴击 → dmg × 2
  元素亲和免疫（史莱姆）：免疫对应元素伤害，且不掉血、不上元素
  受击天赋：帅气闪避(20%归零)、古树反击(来源40%真伤 + 自身atk+15%叠至+150%)
  命中后处理：嗜血回复、起势叠加、燃烧、【重点目标】、元素附着、战败检查

敌人 → 主角:
  敌人技能倍率 → 伤害
  格挡（主角天赋）概率 → 伤害归 0
  护盾（=防御力，每回合刷新）先吸收等量伤害（真实伤害无视护盾）
  坚守 概率 → 回复 12% 最大生命
  hp<=0 → 战败
```

- **防御语义**：主角 `def` 作为**护盾**，每回合初刷新=防御力对应值（`refreshHeroShield`）；不参与常规减伤公式。
- **暴击**：初始暴击率 0，暴击伤害固定 +100%（×2）；暴击率最终限 0~100%；「下次攻击暴击率+100%」用一次攻击型技能后提前失效。

### 6.5 状态系统

- 状态栏：buff 黄框 / debuff 红框 / 中性灰；主角额外展示全场状态。
- 状态**点击**查看详情；词条【】**悬浮**查看解释。
- 状态倒计时 `turns` 在每回合结束 tick；带 `layers`（中毒层数）累加。
- 已实装状态见 `02·十三`（燃烧/束缚/攻击提升/护盾/重点目标/伤害减免/屏息/禁锢/中毒/睡眠）。
- 附带判定：敌人受攻击且处于【睡眠】→ 生命降低提前醒来；主角被【禁锢】时移动无实际效果；被【束缚】时移动无实际效果也不变朝向（队友不受束缚影响）。【燃烧】每回合初流失2%最大生命、【中毒】流失对应层数。
- **水泡（延迟）**：水史莱姆扔出后经过 2 回合（其间有 1 回合允许躲开）才在目标格落下造成【禁锢】2 回合。
- **熊·冬眠唤醒**：唤醒当回合**无法行动**，从下一敌方回合起才行动（并进入【狂躁】）。

### 6.6 逃跑（`tryFlee`）

- 前提：本回合**未移动、未使用主角技能**（队友仍照常自动释放）。
- 成功率 `calcEscapeRate`：`(= (主角逃跑速度 − 敌人速度×剩余生命%) / 100)`，限 0~100%，并在 UI 显示。
- 成功：战斗立即结束、无奖励、**逃跑速度永久 +1**，该格变空地。
- 失败：主角本回合失去行动（跳过），队友照常释放。

### 6.7 战斗胜负与奖励

- **胜利**：击败本场全部敌人 → `endCombat(true)`。
- **失败**：主角 hp<=0 → `endCombatByDefeat`，hp 置 1，健康 -healthPenalty，提示“战斗失败”。健康归零 → Game Over。
- **奖励结算**（`grantVictoryRewards`）：按敌人 `reward` 发物品 + `attrUp` 次属性升级（二选一=攻击+1 / 最大生命+5；三选一加 防御+1；`doubleUp` 双倍、额外掉落 `rate`/`coin5`；狗友生成的猎犬不计奖励）。属性升级会永久写入主角基础属性并在顶部 HUD 即时反映。**最大生命+5 时当前生命同步 +5**（最大生命提升自动同步当前生命是全局默认规则，无需额外说明）。
- 编队人数加成：1/2/3 人 → 敌 atk ×1.00/1.15/1.30、maxHp ×1.00/1.20/1.40（`teamSizeBonus`）。
- **战斗结束日志**：胜利/失败/逃跑统一在末尾保留“最后一条战斗记录 + 战斗结果（奖励明细/健康惩罚/逃跑结果）”。

### 6.8 元素亲和与附着（✅ 当前已实现）

- 史莱姆系列：`AFFIN_IMMUNE` 对应元素**免疫**且常附着该元素（`aura`）。
- `setAura` 设置元素附着标记；附着会顶替旧附着。
- 🧩 **完整元素反应表（蒸发/燃烧/超载/融化/冻结/绽放/感电/激化/超导/扩散/结晶）尚未接入**，仅有“亲和免疫 + 附着标记”这一层，反应触发计算见文末附录B（规划中）。
