## 四、地图系统（js/map.js）

### 4.1 每日生成

- 每天开始时随机生成一张新图；当天固定；次日整图重生成（保留背包、天计数等全局状态）。
- **尺寸随天数渐进**（`mapSizeForDay`，参考值，另加随机波动 ±2，最小 4）：

```text
第1天=4x4   第20天=6x6   第50天=8x8   第100天=9x9   第150天=12x12
```

- **边框**：有效地图为内区 `n×n`，其外围再包一圈「地图外」（void）边框（总边长 n+2）。
- **保底连通**：生成后对「地面格」做连通性检查，若有不连通地块，会把相邻的山脉障碍转成地面作为“桥”，保证所有地面格连通。

### 4.2 每格内容分配（`rollCell`，内区每格独立）

| 内容 | 概率 | 说明 |
|---|---|---|
| 空地 empty | 30% | 进入后触发空地搜索 |
| 事件 event | 25% | 见 4.5 |
| 战斗 battle | 30% | 70% 普通(ordinary) / 30% 艰难(elite)；`boss` 目前仅固定事件被动 |
| 奖励 loot | 10% | 见 4.4 |
| 山脉 obstacle | 5% | 障碍，不可通行 |

- 出生点（`px,py`）从随机一个地面格生成；进入战斗/结束战斗都会把玩家**传送回进入战斗那一格**。

### 4.3 行动力（AP）与移动（js/explore.js）

- `actionPoint` 初始 5，当日上限 `apCap` 初始 5；`睡觉` 时恢复到上限。
- **移动**：只能移动到相邻一格（上下左右）；`行动力<1` 时无法移动，需睡觉进下一天。
- 目标为障碍/地图外 → 只改变朝向、**不消耗 AP**。
- 目标为地面格 → 消耗 1 AP，移动过去并**触发该格内容**；若为战斗格，登录后立即进入战斗。
- 载具：每次真实移动消耗 1 个已选载具次数，耗尽自动切回徒步（见 05）。

### 4.4 拾取 / 奖励（探索）

- **空地搜索**：进入空地触发；档位判定 50% 掉落 2 个同种资源，再 50% 掉落 2 个（可落空停止），至多 3 档=6 个。野外只产自然资源（木/亚麻/果/生肉）。
- **奖励格 Loot（宝箱）**：

```text
<40%      → 2 个随机资源
<90%      → 4 个随机资源
<97%      → 金币 4~10
<99.7%    → 木棒 或 布衣 ×1（永久物品，天赋+1）
其余      → 匕首 或 皮衣 ×1（永久物品，天赋+1）
```

### 4.5 事件（Event，js/event.js）

- 事件格进入后**立即变为空地**（防事件内战斗结束后格子残留）；事件状态存于 `G.activeEvent`，供读档恢复。
- **随机事件池**（进入事件格时等概率抽取一次，测试期各事件出率相等；随机值在事件生成时决定并固化，读档不变）：

| 事件 | 选项 | 效果 |
|---|---|---|
| 无主之物 | 捡起 / 算了 | 捡起→金币+2；算了→离开 |
| 摔倒的老人 | 扶 / 不扶 | 扶→85% 赠随机资源(木/亚麻/果/生肉)，15% 金币减半(向下取整)；不扶→离开 |
| 山野温泉 | 泡温泉 / 休息 / 算了 | 泡→回75%生命；休息→行动力+2（可超上限）；算了→离开 |
| 讨伐任务·暴躁的熊 | 见下 | 首次遇→接支线(占位)；二次遇→战斗(暴躁的熊) / 得路线图×1 |
| 穷追不舍 | 别太嚣张 / 丢块肉 | 战斗(猎犬Pro) / 耗生肉×1离开 |
| 流浪商人 | 看看货 / 不感兴趣 | 买随机商品(波动价20%~160%，需足额) / 行动力+1 |
| 临时起意·钱袋 | 偷偷拿走 / 算了 | 成功率y(10%~95%)；成→金币+x(2~15)+压力+1+好感-2；败→生命=1 |
| 临时起意·面包 | 抢了 / 算了 | 成功率y；成→行动力+4+压力+1+好感-2；败→生命=1 |
| **翻车现场** 🆕 | 买地龙 / 买马车 / 买魔法扫帚 / 买魔法飞毯 | 摔得人仰车翻的载具商人。地龙(必现)/马车(50%)/魔法扫帚(50%)/魔法飞毯(50%)；选项2/3/4独立概率，未出现则后续前移 |
| **常乐·猜大小** 🆕 | 稳一手 / 以小博大 / 帝王之征 / 全押 | 多层级事件（4层状态机）。12张牌(4~8小+0~7大+0~7王)抽3张；三种预测；帝王之征赢→**许愿三选一**（魔法秘籍/生存物资/远行装备）；全押独立赌博（50%翻倍/50%清零） |
| **一塌糊涂的菜园** 🆕 | 拔萝卜 / 算了 | 85% 成功获得蔬菜+行动力-0 / 15% 失败行动力-3 |
| **废弃矿洞** 🆕 | 下矿 / 算了 | 60% 挖到矿石（铁块/紫水晶/钻石等概率）、30% 塌方失 40% HP、10% 铁疙瘩战斗 |
| **道旁的修女** 🆕 | 忏悔 / 算了 | 初始成功率 100%，成功后下次 -5%（最低 50%），失败不减；消耗 1 金币 |
| **蘑菇迷境** 🆕 | 进入蘑菇圈 / 算了 | 10 次独立随机效果：HP ±99%、金币 ±80%~+100%、丢 1 个消耗品、得自然资源、基础攻击 -5~+5 永久、最大 HP -50~+50 永久（整十）、行动力 -6~+6 |

- **熊事件分支**：首次遇（`records.bearQuestStarted` 未置位）→单选项"我了解了"，选后置位接支线；之后任意天再遇→"请村民领路找熊"（进入暴躁的熊战斗）或"要路线图×1"。
- **心理压力 / 好感度**：钱袋/面包事件里 psyStress 字段已实装结算（+1）；修女忏悔事件也消耗金币并可能影响 psyStress。
- **多层级事件引擎**：事件 resolve 返回值支持 `{__continue: true, body, options}` 标记——confirmEventOption 检测到此标记会重新渲染选项而非结束事件，支持无限嵌套推进（常乐·猜大小使用 4 层状态机实现 抽牌→预测→许愿/全押）。
- **事件交互**：正文/标题在剧情区（标题大字金色）；选项在信息区；选中淡绿+确认提示，再点确认→金色→整体 2s 淡出→结果回剧情区。选项数为 1~7 个，过多可滚动。描述为"无"的选项不显示描述行。
- **事件中**：地图可缩放平移但不可移动至新格；编队/商店/睡觉/合成禁用；背包可开但不可使用物品；载具可开可切换但无实质效果。
- **事件完成**：无论选什么，事件格保持空地；结果展示后剧情区可点击清空。

### 4.6 区域

- `G.region` 当前恒为 `wild`（野外），探索资源池因此用自然资源。
- 🧩 **wild/city 区域切换**：`G.region` 未真正切换，“城市”侧资源（金币/空瓶子）与 UI 的区域显示均属**规划中**。
