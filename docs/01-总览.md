## 一、项目是什么

**《在成为勇者之前》**（内部标识 `html-game`）是一款纯前端浏览器游戏，无后端、无需安装，双击 `index.html` 即可运行。

核心循环：

```
探索（格子地图移动、找资源、碰事件、遇敌人）
    ↓  踩到作战格
战斗（回合制、7 元素附着与 10+ 元素反应、多角色共用技能组、自动/连携技能）
    ↓  胜利 / 逃跑
回到探索（地块内容可能已被清空；元素附着留在地块上、下一日生成新地图时统一清除）
    ↓  事件 / 剧情推进 / 天数推进
睡觉（回 HP、永久物品触发效果、存档）
```

引擎：纯 HTML + CSS + 原生 ES2022 JavaScript，零第三方依赖，零打包构建步骤。

## 四、四种运行模式

| 模式 | 触发条件 | 底部显示 | 地图 | 玩家输入 |
|---|---|---|---|---|
| **主菜单** | 首次打开 / 未存档 | — | — | 开始游戏、读档 |
| **探索** | 地图上自由行动 | 剧情区（默认空） | 可缩放拖拽、可点击预览地块 | WASD/鼠标点格 + 前往、iconbar 打开子界面 |
| **战斗** | 踩到作战格 / 剧情强制开战 | 角色技能区 | 简化（无缩放拖拽） | WASD、点击技能 tile、E 连携、F 跳过、Esc 逃跑 |
| **剧情 / 事件** | 触发主线段落或事件 | 剧情区（打字机文字） | 锁定 | 点击推进 / 自动模式 / 跳过 / 选项点击 |

切换函数：`switchMode('explore' | 'combat' | 'story')` —— 负责 DOM class、iconbar 锁、输入拦截。

## 五、新玩家快速上手

1. **打开** `index.html` → 主菜单 → 开始游戏
2. **探索**：WASD 移动主角。每个格子有地形和地块内容；战利品格会掉资源、事件格触发剧情对话、作战格进入战斗
3. **战斗**：踩到作战格后自动进入。主角回合内可：
   - 点击技能 tile 释放对应技能
   - WASD 或点相邻格移动（移动=结束玩家手动阶段的触发条件之一）
   - 按 **F** 跳过（原地不动，结束手动阶段）
   - 按 **E** 释放连携技能（有 2 秒窗口提示）
   - Esc / 右上角逃跑按钮尝试逃跑
4. **睡觉**：iconbar 点「睡觉」结束今天，回满 HP、部分永久物品触发效果
5. **编队**：iconbar 点「编队」切换上场的队友、调整技能组（**技能组只能在编队界面里调**）

## 六、术语与命名规范（给程序员看）

- **地块 vs 格子**：同一概念的两种叫法。面向玩家 UI 用「地块」，代码里任意一处用哪个都可以但统一就好
- **空地块**：战斗里的严谨术语（无实体且无元素附着的地块）；探索里也可以称为「空地」
- **外部地块**（代码里曾叫 `void`）：地图最外圈，不可进入、不可附着、不可受效果影响
- **实体 vs 单位**：同一概念。代码里叫 entity，面向玩家可以说「单位」
- **元素附着**：**只在地块上**（不在实体上）；7 种元素（含风、岩）都可附着；规格曾明确"风与岩无法附着"是旧错误，已删除
- **战斗里无消耗品**：规格里战斗中**不允许打开背包**，消耗品只在探索/剧情/事件里使用
- **永久物品**：带 `permanent:true` 的物品；天赋类永久物品直接加属性，探索类永久物品在睡觉/移动等时机触发；战斗胜利类（幸运硬币）在结算时判定；**可叠加**；**不可出售**
- **载具的狭义语义**：「徒步跋涉」「疾行」虽然在 VEHICLES 表里、在载具页面里可选，但**严格不算载具**，只是普通移动方式。真正的载具指地龙、蘑菇弹、马车、魔法扫帚、飞毯、巧遇这些独立机制
