# 异世界流浪日记 · 玩法机制 · 界面与UI

> 本文是《异世界流浪日记》玩法机制文档系列的第五篇，对应游戏代码模块**「界面与UI」（js/ui.js、css/style.css）**。
> 内容来源《玩法机制介绍-总篇》的：十、界面与UI；十一、文字风格与词条系统。
> 前端硬性规范：**一切展现给玩家看的文本一律中文**。

---

## 十、界面与UI（美术 + 文字规范）

### 10.1 美术定位

- 极简：文字+数值为主体；极少立绘（有也用图标）；背景/区域色区分区域但不只黑/白。
- 文风：多数日常=生存风格（他们并非勇者，堪称流浪）；少数日常=温馨/喜剧；关键转折或结局=悬疑/冷峻（设计若干好结局）。

### 10.2 地图表现

- 俯视格子地图；每格近似正方形且四角圆滑；滚轮缩放、拖拽平移（仅视觉）。
- 格子分界鲜明。主角=简单小人（不随朝向变），其格带小箭头显朝向；敌人同法但箭头颜色不同区分；队友/NPC 很少上地图（多数只文字剧情：名字+对话，无形象）。
- 不同内容用图标：普通敌人/精英敌/Boss敌/事件/奖励/资源 各一种图标；更细类（史莱姆vs哥布林）不靠图标，交给文字区。点击格子可在文字区预览部分信息（有意保留惊喜/惊吓）。

### 10.3 布局（自上而下 / 从左到右）

```
屏幕顶部横栏：健康值 | 天数 | 所在区域 | 主角攻击力 | 防御力 | 生命值/最大生命值 | 金币 | 行动力/上限
  （攻/防/hp最重要故置顶；各信息留空隙不重叠）
顶部横栏下一行（从左到右）：任务 / 编队 / 角色 / 背包 / 睡觉 / 设置 [ / 商店 ]
  商店图标仅特定阶段显示（含第1~2天隐藏），其他经其它方式进入
  【睡觉】=独立按钮，绝不放进设置内
屏幕左中部=【行动记录】（玩家可见名即"行动记录"，不得叫"文字区"）：探索获得/遭遇、
  战斗行动与伤害数值等玩法层细分数据
屏幕右中侧=非战斗标题【事件 / 选择】（事件选项）；战斗标题【插曲】（【额外回合】/短时插入的对话/特殊效果）
  信息展示归属行动记录，本区不放"信息"
屏幕中下方=【剧情/战斗技能】是同一区域，按模式切换、绝不并存：
  非战斗(mode-story)=标题【剧情】：对话(名字独占空间)+旁白(无名字)
  战斗(mode-combat)=标题【战斗 · 技能】：队伍+技能列表+技能详细+天赋
```

**战斗技能域（mode-combat，中下）**：显示队伍角色名，点击切换（默认第1个）；查看并选择/使用技能；被选技能显示名字+详细描述；可查看天赋（小框显名字，再点弹窗显内容）。

**交互**：鼠标点击 与 WASD 等效。探索移动两法任选其一：①点击地图格子→点「前往」（防止误入，先预览）；②WASD 直接移动。战斗：WASD 移动（移动即结束我方回合）/ Q 释放已选技能；点击敌人=选为技能目标。/ 选项=二次确认制（第一次选中、第二次同项=确认）。

### 10.4 全中文化（前端硬性规范）

- **一切展现给玩家看的文本一律中文**（本游戏即中文游戏）。代码/变量可用英文（`HP`、`wood` 等），但**前端渲染文本必须为中文**：如 生命（非HP）、天数（非D），木材/果子/亚麻/生肉/金币/空瓶子（非 wood/fruit...）、存档位第X天（非Dx）。
- 资源中文映射，实现统一用一张 zh 映射表（如 `RES_ZH`）。

### 10.5 图标功能

- 任务→任务页（列出当前任务；引导剧情的任务；已完成单独分类也显示）。
- 编队→编队页（选至多3已解锁角色，常需含主角，调整一二三号位）。
- 角色→角色界面（大，展示所有角色：属性详细、攻击力、技能、羁绊等级、好感度、逃跑速度、个人故事；每级羁绊=10点好感；未了解处用?隐藏；作者未写处写"暂未更新"；每角色单页，不并列）。
- 背包→大背包界面（分类展示所有资源/技能书/剧情道具/任务道具等）。
- 睡觉→独立按钮，直接进入下一天（入口=图标行，不放设置内）。
- 设置→设置界面（存档 / 读档 / 返回主界面；不含睡觉）。
- 面板尺寸：背包/角色/编队/任务等属**大内容面板**，打开时允许遮挡屏幕、尺寸必须足够大（宜近全屏、可滚动），不得小窗口。存档/确认等轻量弹窗可用小窗。

## 十一、文字风格与词条系统

### 11.1 字体 / 元素着色

- 普通字：白/黑/黄均可；不重要(玩笑)用灰。
- 出现「元素伤害/元素附着」等表述时，元素名替换为对应色：
  `火red 水blue 草green 雷purple 冰cyan(青) 风lightBlue 岩brownOrGray`
- **例外**：技能名/日常聊天误含元素词时不改色（如技能「似水流年」中"水"不改色）。规则在文字区/剧情区/任何地方生效。

⚠️ 实现注意：由于 Markdown 里元素着色无法表达，请在 **代码渲染层** 用 `<span class="elem-火">…</span>` 等方式实现；本规格书仅声明规则与色值，不在这里写色。

### 11.2 词条系统（Term）

- 定义：1) 技能描述中用 `【】` 包住的效果名=词条；2) 引用别的技能时，该技能名=词条；但自己技能描述内，技能名不视为词条。
- 表示：所有词条处用 *下划线 + 黄色字体*。悬浮弹出小弹窗显示该词条具体描述。所有词条一致解释，不因已介绍过而省略后续标注。
- 完整词条库见「02·数据与常量」附录A。
