# 异世界流浪日记 · 玩法机制 · 界面与UI

> 本文是《异世界流浪日记》玩法机制文档系列的第五篇，对应游戏代码模块 **「界面与UI」（js/ui.js、css/style.css，辅助 js/craft.js、js/vehicle.js）**。
> 前端硬性规范：**一切展示给玩家的文本一律中文**；文字配色一律浅色（白/灰白/红/黄/金），仅在白底上可用黑字。以最新代码为准。

## 十、界面与UI

### 10.1 整体布局（index.html）

```
┌────────────────────────────────────────────────────────────┐
│ 顶部 HUD：#hud（健康/天数/区域/攻击/防御/生命/金币/行动力）        │
│ 图标行  ：#iconbar（任务/编队/角色/背包/睡觉/设置/商店/合成/载具）  │
│ 左=行动记录 #leftLog · 中=地图 #mapWrap · 右=信息 #rightPanel     │
└────────────────────────────────────────────────────────────┘
下方 #bottom 按模式切换：
  mode-story  = 剧情区（#storyBody，标题+正文打字机逐字显示）
  mode-combat = 战斗技能域（#combatZone，角色卡+技能+详情+天赋）
  事件中（eventState）复用剧情区，选项显示在右侧信息区 #promptZone
```

- 顶部 HUD 字段：健康 / 天数 / 区域 / 攻击 / 防御 / 生命(当前/最大) / 金币 / 行动力。
- 图标行：任务 / 编队 / 角色 / 背包 / 睡觉 / 设置 / 商店 / 合成 / 载具。
  「睡觉」是独立按钮，不放设置内。**战斗/事件中**：编队/睡觉/商店/合成四项置灰（`.dis`）并禁开，背包仍可打开查看（隐藏“使用”按钮）；事件中载具可开可切但无实质效果。
- **事件选项（js/event.js）**：`#promptZone` 内 `.ev-opt`；选项名白底黑字大字单独一行，描述黑底灰白小字（描述为“无”则不显示该行）；单击选中→淡绿底+选项名右侧“你确定这么做？”；点击别处取消选中；再点确认→金色→整体 2s 淡出→结果回剧情区。选项 1~7 个，过多可滚动。
- **剧情区打字机**：事件标题/正文与结果、以及普通剧情文字均以约 30 字/秒逐字显示；点击剧情区：打字中→立即显示整段；已打完→推进到下一段（事件正文段间需点击推进，出选项处不可跳过）；已是最后一段/结果→点击清空。

### 10.2 地图表现

- 俯视格子地图，每格近似正方形；`mapViewport` 支持**滚轮缩放**（0.5~2 倍）与**拖拽平移**（仅视觉）。
- 主角=`.player`（带朝向箭头 facing-*）；敌人显示图标（emoji）+ 血条 `.hpbar` + 朝向 `efacing-*`。
- 内容图标：战斗 ⚔ / 紧急作战 ⚠️ / boss 💀 / 战利品 🎁 / 事件 ❓ / **稀有动物(持路线图时) 🐻 金标**；山脉=`.obstacle`、地图外=`.void`。

### 10.3 战斗技能域（mode-combat）

- **角色卡** `#allyBar`：每张卡显示 名称 + 元素 ·号位；点击或 `F1/F2/F3` 切换当前角色（`.active` 高亮）。
- **属性行** `#charAttrs`：主角显示 攻击/生命/防御/暴击率/逃跑速度；队友显示 攻击/暴击率。
- **状态栏** `#statusBar`：主角额外显示全场状态；buff 黄框、debuff 红框、中性灰；横向滚动；点击查看详情。
- **技能列表** `#skillList`：攻击/辅助标签 + 名称（带「·等级N」+黄字数值）+ “已用”标记；`1/2/3` 选技能、`4`=逃走（显示成功率%）；再次点击或 `Q` 释放。
- **天赋区** `#talentBox`：小框显示名字，点击（或悬浮触发 popover）查看内容。
- **技能详情** `#skillDetail`：显示所选技能名与完整描述（公式+当前约值+词条）。

### 10.4 面板（Modal）与快捷键

- `openModal(title, html, size, {replace})`：尺寸 small / wide / full；`replace:true` 原地刷新不压栈（合成/载具/商店调量用）。
- **ESC**：有弹窗时退回一层（`modalStack`）；无弹窗时打开设置；主界面/游戏结束界面无效果。
- **快捷键**：探索 `WASD`；战斗 `WASD`/`1·2·3·4`/`Q`/`F1·F2·F3`；`E` 合成；`T` 载具；`ESC` 退回。

### 10.5 各功能面板

- **合成 `craft.js`**：左右两列配方卡；每配方独立「合成」按钮；滑块/±调一次数量；点配方里资源/物品弹预览（`.craftlink` 委托）；递增耗材与上限有提示。
- **载具 `vehicle.js`**：格子式 `.vslot` 逐格展示每个载具；当前选中浅黄 `.sel`；有限次数显示“剩 N 次”。载具**选中后保持使用直到次数耗尽**（不再每次移动强制切回徒步）；耗尽时自动切回徒步并在行动记录提示一次；无限载具可一直使用。
- **商店 `ui.js`**：左右两列；购买与卖出共用同一滑块设数量；物品不可售置灰；不足/超额提示直接显示在面板内（`shopMsg`），不进行动记录。
- **背包**：顶部三个居中标签按钮 `消耗品 / 永久物品 / 任务道具`（分类由物品数据自动判定），点击切换；某分类下无物品则显示“此类下没有物品”（允许点击空分类）；关闭背包再次打开时自动重置到「消耗品」。同种物品自动合并显示数量；金币独立显示顶部；食物有「使用」按钮（战斗/事件中隐藏）；点物品名可预览说明。
- **角色页**：
  - 顶部角色按钮行**居中**（无论几个角色始终保持居中）；**关闭角色页后再次打开时自动重置为主角 + 技能展示**（仅切换默认显示，不清任何数据）。
  - 整个角色页采用**左 4 栏 / 右 1 栏**两栏布局，**右侧栏常驻**不因切换二级页面而消失。右侧栏从上到下依次是：角色名字（固定显示）、羁绊等级 + 好感度（**任何方式引发的变化都会实时反映**，无需关闭重开页面）、「技能展示 / 调整技能 / 交互 / 羁绊等级效果 / 故事」五个大按钮。
  - **战斗或事件中打开角色页时**：「调整技能」与「交互」两个按钮自动置灰禁点（`.dis`）。
  - **技能展示**：天赋 + 技能列表（含「·等级N」与完整描述、携带标记）；顶部属性行字体略大（主角显示 `攻击 / 最大生命 / 防御 / 逃跑速度 / 健康 / 行动力上限`，队友显示 `攻击 / 元素属性`；本界面显示**基础值**，战斗内查看时也只显示基础值，不会因战斗加成改变）。
  - **调整技能**（原名「携带技能调整」，战斗/事件中禁开）：至多选 3 个技能（勾选 ☑，超过提示），保存后生效。
  - **交互**：见 §十.6 交互界面。
  - **羁绊等级效果**：主角「无羁绊等级」；队友显示 0~10 级真实解锁文本（`BOND_TEXT`），标注当前级、当前好感度。
  - **故事**：主角/队友背景占位。
- **编队**：一二三号位顺序调整（影响战斗自动释放顺序），显示羁绊等级。「快捷编队」进入换人：**主角可临时移出编队**，点卡片切换 1/2/3 号位；在确认 / ESC / 点击换人界面外退出时校验——**新编队必须含主角且至少 1 人**，不合规则则**不保存、按原编队保留**并提示玩家。
- **任务**：左侧主线/支线列表，右侧目标与奖励。带「接取钩子」的任务首次遇对应事件后才显示；达标后标记「待领取」，点击「领取奖励」手动发放（`claimTask`）；物品奖励可点击查看说明。
- **设置**：存档 / 读档 / 返回主界面（战斗中“存档（回本次战斗开始时）”；事件中“存档（回本次事件开始时）”）。

### 10.6 交互界面（角色页·交互标签页）

- **布局**：左侧一列可选项按钮（各角色不同），右侧为对话区。
  - **打字机行为**：约 40ms/字 逐字显示；**在打字中途再次点击聊天/送礼**时，先把上一段未打完的文本立即显示完整（保留它在原地），再在下一行开始新内容的打字；两段文字都不会丢失。
  - **历史保留**：角色独立历史记录，退出角色页/切换到其他二级页面**不会清除**已有对话。
  - **历史上限**：按**总字符数**限制（上限 3000 字符），不是按条数。字数超上限时**从最早的消息开始逐条删除**直到剩余能容纳，**同步从 DOM 中移除**（对话区不会变上下滑动的滚动区）。
- **夏阳**：聊天（成功率 50%，固定）/ 投喂 / 送礼。
- **陆悠悠**：聊天（成功率 `x`，`x` 为每日随机 -20%~+60% 的**整数**初始成功率，负值必失败）/ 送礼。成功率**实时显示在按钮上**，每次聊天后按钮文字立刻更新为新的整数成功率（无小数）。
- **聊天**：每次消耗 **1 行动力**（不足则无效并提示）；成功率实时显示在按钮上（`聊天（成功率 x%）`），始终为整数（计算中允许临时小数，但结果和 UI 均四舍五入到整数）。
  - 夏阳成功 好感+1，失败 好感+0。
  - 陆悠悠成功 好感+1 且当日成功率 **+2~+4 整数 %**（四舍五入）；失败 好感+0 且当日 **-2~-4 整数 %**；结果夹在 0~100 区间内。
- **投喂（仅夏阳）**：自动消耗背包中回复量最少的食物 1 个；**每天仅第一次**投喂好感度+1（界面有说明）。
- **送礼**：点击进入「选择礼物」三级页（遮挡左侧，CSS overlay）：
  - 按格列出背包中所有**可消耗品**（`GIFT_EXCLUDE` 含永久道具和金币）及个数；点选格子变高亮、再点取消；一次只能送 1 件。**礼物选择面板内不再整页重绘**，仅切换选中格子的 class——因此切换选择时面板不会闪。
  - 「确认送出」→ 先从 DOM 里移除送礼面板，再扣物品、按**隐藏物品喜好度**（`ITEM_LOVE`）增减好感度、追加对话文本（用 DOM 追加，不会把已有的对话历史清掉）。
  - ESC / 点击页面外 / 「取消」按钮均可关闭；**不耗物品、不耗次数、不触发对话**。关闭时直接从 DOM 移除 overlay，不动对话历史。
  - 每个角色**每 3 天只能送礼 1 次**（独立计算、不可储存），界面有冷却提示。
- **关闭**：交互界面右上角 ✕ 与 ESC 可关（但送礼面板打开时 ESC 优先关送礼面板，再次 ESC 才关交互）。

### 10.7 词条与悬浮

- **词条【】**：技能/描述中的效果名；悬浮 `.term` 显示解释（数据源 `TERMS`）。
- **状态/天赋/物品**：点击弹 popover（`openPopoverNear`，超出视口自动翻转防止遮挡）。
- 元素着色：火红 / 水蓝 / 草绿 / 雷紫 / 冰青 / 风浅蓝 / 岩棕。

## 十一、文字与视觉规范

- **中文口径**：所有玩家可见文本一律中文，禁止英文界面词（生命非 HP、天数非 Day、木材非 wood 等）。资源中文映射统一用 `RES_ZH`。
- **配色**：浅色为主；等级提升数值用黄字 `.lvlup`（#ffd23f）；暴击提示 `.crit-hint`；攻击标签/辅助标签/天赋标签用不同色区分。
- **风格**：极简，文字+数值为主体；极少立绘（用图标/emoji）；区域用背景/区域色区分。
