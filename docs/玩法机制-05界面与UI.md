# 异世界流浪日记 · 玩法机制 · 界面与UI

> 本文是《异世界流浪日记》玩法机制文档系列的第五篇，对应游戏代码模块 **「界面与UI」（js/ui.js、css/style.css，辅助 js/craft.js、js/vehicle.js）**。
> 前端硬性规范：**一切展示给玩家的文本一律中文**；文字配色一律浅色（白/灰白/红/黄/金），仅在白底上可用黑字。以最新代码为准。

## 十、界面与UI

### 10.1 整体布局（index.html）

```
┌────────────────────────────────────────────────────────────┐
│ 顶部 HUD：#hud（健康/天数/区域/攻击/防御/生命/金币/行动力）        │
│ 图标行  ：#iconbar（任务/编队/角色/背包/睡觉/设置/商店/合成/载具）  │
│ 左=行动记录 #leftLog · 中=地图 #mapWrap · 右=信息 #rightPanel     │
└────────────────────────────────────────────────────────────┘
下方 #bottom 按模式切换，二选一、绝不并存：
  mode-story  = 剧情区（#storyZone / 标题「剧情」）
  mode-combat = 战斗技能域（#combatZone，角色卡+技能+详情+天赋）
```

- 顶部 HUD 字段：健康 / 天数 / 区域 / 攻击 / 防御 / 生命(当前/最大) / 金币 / 行动力。
- 图标行：任务 / 编队 / 角色 / 背包 / 睡觉 / 设置 / 商店 / 合成 / 载具。
  「睡觉」是独立按钮，不放设置内。**战斗中**：编队/睡觉/商店/合成四项置灰（`.dis`）并禁开，背包仍可打开查看（隐藏“使用”按钮）。

### 10.2 地图表现

- 俯视格子地图，每格近似正方形；`mapViewport` 支持**滚轮缩放**（0.5~2 倍）与**拖拽平移**（仅视觉）。
- 主角=`.player`（带朝向箭头 facing-*）；敌人显示图标（emoji）+ 血条 `.hpbar` + 朝向 `efacing-*`。
- 内容图标：战斗 ⚔ / 紧急作战 ⚠️ / boss 💀 / 战利品 🎁 / 事件 ❓；山脉=`.obstacle`、地图外=`.void`。

### 10.3 战斗技能域（mode-combat）

- **角色卡** `#allyBar`：每张卡显示 名称 + 元素 ·号位；点击或 `F1/F2/F3` 切换当前角色（`.active` 高亮）。
- **属性行** `#charAttrs`：主角显示 攻击/生命/防御/暴击率/逃跑速度；队友显示 攻击/暴击率。
- **状态栏** `#statusBar`：主角额外显示全场状态；buff 黄框、debuff 红框、中性灰；横向滚动；点击查看详情。
- **技能列表** `#skillList`：攻击/辅助标签 + 名称（带「·等级N」+黄字数值）+ “已用”标记；`1/2/3` 选技能、`4`=逃走（显示成功率%）；再次点击或 `Q` 释放。
- **天赋区** `#talentBox`：小框显示名字，点击（或悬浮触发 popover）查看内容。
- **技能详情** `#skillDetail`：显示所选技能名与完整描述（公式+当前约值+词条）。

### 10.4 面板（Modal）与快捷键

- `openModal(title, html, size, {replace})`：尺寸 small / wide / full；`replace:true` 原地刷新不压栈（合成/载具/商店调量用）。
- **ESC**：有弹窗时退回一层（`modalStack`）；无弹窗时打开设置；主界面/游戏结束界面无效果。
- **快捷键**：探索 `WASD`；战斗 `WASD`/`1·2·3·4`/`Q`/`F1·F2·F3`；`E` 合成；`T` 载具；`ESC` 退回。

### 10.5 各功能面板

- **合成 `craft.js`**：左右两列配方卡；每配方独立「合成」按钮；滑块/±调一次数量；点配方里资源/物品弹预览（`.craftlink` 委托）；递增耗材与上限有提示。
- **载具 `vehicle.js`**：格子式 `.vslot` 逐格展示每个载具；当前选中浅黄 `.sel`；有限次数显示“剩 N 次”；移动消耗、耗尽自动切回徒步。
- **商店 `ui.js`**：左右两列；购买与卖出共用同一滑块设数量；物品不可售置灰；不足/超额提示直接显示在面板内（`shopMsg`），不进行动记录。
- **背包**：全屏格子化，同种自动合并显示数量；金币独立显示顶部；食物有「使用」按钮（战斗隐藏）；点物品名可预览说明；**战斗中不可使用物品**。
- **角色页**：展示 属性(攻击/最大生命/防御/逃跑速度/健康/行动力上限) + 天赋 + 技能 + “调整携带技能”入口（至多带 3 个）。
- **编队**：一二三号位顺序调整（影响战斗自动释放顺序）；显示羁绊等级。
- **任务**：当前任务记录（开局固定两条）。
- **设置**：存档 / 读档 / 返回主界面（战斗中文案为“存档（回本次战斗开始时）”）。

### 10.6 词条与悬浮

- **词条【】**：技能/描述中的效果名；悬浮 `.term` 显示解释（数据源 `TERMS`）。
- **状态/天赋/物品**：点击弹 popover（`openPopoverNear`，超出视口自动翻转防止遮挡）。
- 元素着色：火红 / 水蓝 / 草绿 / 雷紫 / 冰青 / 风浅蓝 / 岩棕。

## 十一、文字与视觉规范

- **中文口径**：所有玩家可见文本一律中文，禁止英文界面词（生命非 HP、天数非 Day、木材非 wood 等）。资源中文映射统一用 `RES_ZH`。
- **配色**：浅色为主；等级提升数值用黄字 `.lvlup`（#ffd23f）；暴击提示 `.crit-hint`；攻击标签/辅助标签/天赋标签用不同色区分。
- **风格**：极简，文字+数值为主体；极少立绘（用图标/emoji）；区域用背景/区域色区分。
