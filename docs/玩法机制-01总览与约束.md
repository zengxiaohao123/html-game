| 键 | 值 |

## 十六、当前实现状态（MVP，已上线）

> 用 `index.html`（main 分支 → Cloudflare Pages）可试玩。下列为当前已落地/未落地，供后续开发对齐，避免重复造轮子或误判为缺失。

- ✅ 已实现：
  - 每天随机地图（尺寸随天数渐进：d1=4×4…d150=12×12）+ 保底连通
  - 探索：点击格子+「前往」 或 WASD 连续移动（等价）；行动力 AP；资源递进采集（0/2/4/6 同种，50%递减档）
  - 格子内容：敌人/宝箱/事件/空地；宝箱与简单事件（掉落/温泉/虚惊）
  - 回合战斗：WASD 移动 + Q 释放已选技能；主角 5 攻击技（携带3）；敌人逼近/贴身攻击；点击敌人=选目标
  - 基础元素附着与反应：蒸发 / 燃烧 / 绽放；词条悬浮弹窗
  - 睡觉进下一天（独立按钮）+ 8 槽 localStorage 存档 + 健康值归零 Game Over
  - UI：顶部状态栏 / 图标行(任务·编队·角色·背包·睡觉·设置·商店) / 行动记录(左) / 事件·选择或插曲(右) / 剧情或战斗技能(中下同区按模式切换)；前端口径一律中文；大面板
- ⚠️ 已实现但为 MVP 简化（后续按本规格书逐步补齐）：
  - 敌人仅 3 种临时占位（哥布林/毒蛾/岩狼），未含逃跑/蓄力/专属AI
  - 伤害公式只实现 攻击力×减伤×技能倍率，未含完整乘区/暴击/元素抗性/最终伤害加成
  - 战斗仅 1 敌且为单体；未含多敌、朝向严格结算、额外回合、队友
  - 元素反应仅 3 条（蒸发/燃烧/绽放），未含扩散/结晶/超载/感电/冻结/融化/激化/超导
  - 图鉴/剧情分支/城市区域切换为占位或未做（商店已实现基础购/售，物品见 02·3.5）
- ❌ 未实现：队友角色（夏阳/陆悠悠/许泠朦/叶唯安/潘天宇）、逃跑机制、完整词条库、装备/合成、心理压力、图鉴内容、潘天宇数据
