## 〇、给未来 AI 的文档使用说明（必读）

### 阅读顺序（新会话 / 接手开发时按此顺序）

1. **本文「01·总览与约束」** → 先读「项目与运行约束」「文档系列构成」「当前实现状态」，快速对齐“游戏是什么、哪些已上线、哪些是规划”。
2. **「02·数据与常量」** → 角色 / 敌人 / 技能 / 状态 / 物品 / 词条；敌人“✅已实现 vs 🧩仅数据”见该篇 14 节。
3. **「03·地图与探索」** → 地图生成 / AP / 移动 / 拾取 / 宝箱 / 事件。
4. **「04·战斗系统」** → 回合结构 / 敌人AI / 伤害公式 / 元素亲和与状态 / 逃跑。
5. **「05·界面与UI」** → HUD / 图标栏 / 布局 / 面板 / 词条悬浮。
6. **「06·存档与进度」** → 存档位 / 睡觉 / 读档。
7. `docs/开发日志与进度.md` = **当前快照 + 待办清单**（工作记录，非玩法权威）。
8. 仓库根目录 `AGENT_CONTEXT.md` = **操作锚点**（仓库 / 部署 / 连接状态 / Agent 操作规范）。

### 修改文档的逻辑（必须遵守）

1. **代码为准**：文档里任何标「已实现 ✅」的内容必须能在当前代码中找到对应实现；找不到就归入「规划中/未实现 🧩」，绝不伪装成已上线。
2. **改代码必同步文档**：改了功能/数值，先改代码，再回文档对应分篇同步；删除旧版本的历史改动记录，只保留“当前快照”口径，不用“删除线+新内容”双写。
3. **数据优先写代码**：数值/玩家向数据先改 `js/data.js`（如状态 `ST`、词条 `TERMS`、敌人 `ENEMIES`、物品 `ITEMS`），再由本文档 02 摘录。
4. **未实现功能的新规格**：统一写入「当前实现状态」下的「规划中/未实现」清单，不散落各处。
5. **中文口径**：所有玩家可见文本一律中文（前端渲染强约束）；文档亦使用中文。
6. 改完任何一版后，回到 `AGENT_CONTEXT.md` 按其中第七条规则同步更新。

## 二、项目与运行约束

| 键 | 值 |
|---|---|
| 类型 | 纯前端单机 HTML/JS。经典全局脚本按依赖顺序加载：data→save→map→explore→combat→ui→craft→vehicle→main；无构建步骤 |

| 无后端 | 存档用浏览器 localStorage（8 个存档位），不联网、不排行、不收集用户数据 |

| 存档 | 睡觉自动存档 / 手动任意时刻；战斗中存档=以战斗开始时为锚点 |
| 存档键 | `yysw_saves`（localStorage），`MAX_SAVES=8` |

## 三、当前实现状态（以最新代码为准 ✅ / 🧩）

### ✅ 已上线（可在 Cloudflare 页面试玩）

- **核心循环**：每天随机地图 → 探索收集/遇敌 → 回合战斗 → 睡觉进下一天（自动存档）；健康归零即 Game Over。
- **角色**：主角 + 夏阳 + 陆悠悠（3 人队伍，123 号位可调换；每人可携带至多 3 个技能）。
- **探索**：点击格子+「前往」或 WASD；行动力 AP；空地搜索（档位 50%，至多 6 资源）；宝箱 / 事件（商人/温泉/虚惊/迷路旅人）。
- **战斗**：移动即结束我方回合；队友自动释放已选技能；敌人回合=移动+技能；状态系统（燃烧/束缚/中毒/禁锢/睡眠等）；护盾（=防御力）；暴击（×2）；格挡/坚守；逃跑系统；元素亲和（史莱姆免对应元素）。
- **敌人 19 个**：全部技能与天赋已接入（史莱姆系列 + 中二病/蛇/古树/猎犬/镖客/熊/机关等），多敌同时行动（狗友/集群）；见 `02·十四`。
- **系统功能**：合成（`craft.js`，E 键）、载具（`vehicle.js`，T 键）、商店、背包、角色页、编队、任务、设置、8 槽存档读档、ESC 退回、词条/状态悬浮、地图缩放拖拽。

### 🧩 规划中 / 未实现（不误程为已上线）

- **完整元素反应系统**（蒸发/融化/超载/冻结/绽放/感电/激化/超导/扩散/结晶）：当前仅实现元素亲和免疫与附着标记（`setAura`），反应表为**规划中**，见 `04` 附录。
- **队友占位天赋**：夏阳（活力满满/好奇心/心想事成/涅槃）、陆悠悠（巧手/烹饪/蹁跹/风息·风转）等目前为文本/部分数值，完整结算未接。
- **许泠朦 / 叶唯安 / 潘天宇**：角色数据在代码中**尚未出现**（早期规格）。
- **召唤物 / 结界 / 额外回合**（草史莱姆召唤、水精灵、绽放/离离枯荣结界、泠朦额外回合）：均为**规划中**。
- **区域切换（wild/city）**：`G.region` 实际恒为 wild，城市切换未真正生效。
- **完整剧情线 / 图鉴 / 数值平衡 / 心理压力系统**：规划中。

## 四、操作与快捷键

- 探索：`WASD` 移动；点击格子 +「前往」确认移动。
- 战斗：`WASD` 移动（移动即结束我方回合）；`1/2/3` 选技能、再按一次或 `Q` 释放（`4` 可选中“逃走”）；`F1/F2/F3` 切换角色。
- 界面：`E` 合成；`T` 载具；`ESC` 退回一层弹窗（无弹窗时打开设置）。
- 战斗中禁开：编队 / 睡觉 / 商店 / 合成（图标置灰）；背包仍可打开查看。
